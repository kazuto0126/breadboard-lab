給 AI 工具用（MCP）

讓 Cursor、VS Code 的 Copilot、Gemini CLI、Claude Desktop、Claude Code 等支援 MCP 的 AI 工具，直接幫你放元件、接線、檢查、AI 佈線、模擬， 也可以出真值表題目、畫邏輯圖、轉成麵包板並比對。結果存成 .json 檔，在 Breadboard Lab 網頁用「檔案 → 匯入 JSON」打開。

適合會寫程式、電腦上已經有 Node.js 的人。只用網頁的話不需要這一頁。

1. 需要什麼

  • Node.js 22 以上（nodejs.org，選 LTS 版本）。打開終端機（Windows 是「命令提示字元」或 PowerShell）輸入 node --version，看到 v22 以上的數字就可以。
  • 一個支援 MCP 的 AI 工具（下面第 3 節）。

2. 下載並放好

下載 breadboard-lab-mcp.mjs

  1. 把檔案放在固定的位置，例如 Windows 的 C:\tools\、macOS 的 ~/tools/（之後不要再搬，設定裡寫的是這個位置）。
  2. 建一個放電路檔的資料夾（工作資料夾），例如 Windows 的 C:\circuits、macOS 的 ~/circuits。 AI 只能讀寫這個資料夾（和裡面的子資料夾）的 .json 電路檔，不會碰到別的檔案。
  3. 設定裡用 --folder 告訴它工作資料夾在哪裡。路徑請寫完整的路徑。

3. 在 AI 工具裡設定

選你的電腦：

下面的路徑是例子（檔案在 C:\tools 或 /Users/你的帳號/tools、工作資料夾是 C:\circuits 或 /Users/你的帳號/circuits），請換成你自己的。 JSON 裡 Windows 的 \ 要寫兩個（\\）。設定好之後把 AI 工具完全關掉再打開。各工具的設定方式在 2026-10-19 照官方文件查證過。

Cursor

設定檔：所有專案都能用的 ~/.cursor/mcp.json（Windows 是 %USERPROFILE%\.cursor\mcp.json），或只給一個專案用的 .cursor/mcp.json。 （Cursor 文件）

{
  "mcpServers": {
    "breadboard-lab": {
      "type": "stdio",
      "command": "node",
      "args": ["C:\\tools\\breadboard-lab-mcp.mjs", "--folder", "C:\\circuits"]
    }
  }
}
{
  "mcpServers": {
    "breadboard-lab": {
      "type": "stdio",
      "command": "node",
      "args": ["/Users/你的帳號/tools/breadboard-lab-mcp.mjs", "--folder", "/Users/你的帳號/circuits"]
    }
  }
}

Claude Code

在終端機執行一次（--scope user 是所有專案都能用），再用 claude mcp list 看有沒有連上。（Claude Code 文件）

claude mcp add --scope user breadboard-lab -- node C:\tools\breadboard-lab-mcp.mjs --folder C:\circuits
claude mcp add --scope user breadboard-lab -- node ~/tools/breadboard-lab-mcp.mjs --folder ~/circuits

Codex CLI

OpenAI 的 Codex（命令列、桌面 App、編輯器擴充功能共用同一份設定）。在終端機執行一次：

codex mcp add breadboard-lab -- node C:\tools\breadboard-lab-mcp.mjs --folder C:\circuits
codex mcp add breadboard-lab -- node ~/tools/breadboard-lab-mcp.mjs --folder ~/circuits

也可以直接編輯 ~/.codex/config.toml（Windows 是 %USERPROFILE%\.codex\config.toml），加上下面這段（這是 TOML 格式；Windows 的路徑用單引號，\ 不用寫兩個）。 用 codex mcp list 確認，在 Codex 裡輸入 /mcp 看有沒有連上。（Codex 文件）

command = "node"

[mcp_servers.breadboard-lab]

args = ["/Users/你的帳號/tools/breadboard-lab-mcp.mjs", "--folder", "/Users/你的帳號/circuits"]

4. 第一次可以怎麼問

  • 「出一題 3 個輸入 A、B、C 的多數決題目，產生邏輯圖，轉成麵包板，再和題目比對，存成 majority.json。」
  • 「在 xor.json 用 74LS00 做一個 XOR：放好 IC、開關和 LED，接線、檢查，再跑 AI 佈線。」
  • 「題目是 W X Y Z 四個輸入，顯示器 S1 顯示 WXYZ 加 1（9 之後是 0，10–15 不在乎），只用 NAND 畫邏輯圖。」
  • 「用布林式 X = AB + A'C 出題，化簡後畫邏輯圖、轉成麵包板，再和題目比對，存成 x.json。」
  • 「列出工作資料夾裡的電路檔，檢查 lab3.json 哪裡接錯，告訴我怎麼改。」

5. 結果怎麼看

AI 改的是工作資料夾裡的 .json 檔。打開 Breadboard Lab 網頁，用「檔案 → 匯入 JSON」選那個檔案，就能看到麵包板、邏輯圖與題目。

6. 有哪些工具

工具做什麼
list_files、new_circuit、circuit_summary列出電路檔、建立新檔、看摘要
list_parts、place_part、add_wire、set_part、remove查元件、放元件、接線、改設定與名稱、刪除
check_circuit、auto_route、simulate檢查、AI 標準佈線、邏輯模擬
logic_set、logic_truth_table、logic_to_breadboard、check_against_diagram寫入邏輯圖（可以用 IC 方塊、計數器與單顆 D / JK 正反器）、真值表（時序電路是時序表與文字波形）、轉成麵包板（大電路自動用兩塊 EIC-1106）、依名稱比對
task_set、task_show、task_to_diagram、task_check真值表題目：寫入、化簡、產生邏輯圖、和邏輯圖與麵包板比對
share_link把電路做成連結，點開就在網頁上看到（不用匯入檔案）
rename_circuit改電路的名稱（網頁左上角顯示的名稱）

接線規則：每條導線只能水平或垂直，不能斜；要轉彎就分成兩條線（轉角接在同一排相通的孔）；兩條線不能重疊，也不能交叉； 線不能跨過 IC（上下、左右都不行）。AI 工具用 add_wire 接不合規則的線會被拒絕並說明原因；auto_route 與 logic_to_breadboard 接出來的線都符合這些規則。

7. 更新

重新下載 breadboard-lab-mcp.mjs 蓋掉舊的檔案，再把 AI 工具完全關掉重開。看目前的版本：

node C:\tools\breadboard-lab-mcp.mjs --version
node ~/tools/breadboard-lab-mcp.mjs --version

版本號是建置的日期（例如 2026.10.19）。

8. 常見問題

AI 工具說找不到 node

先在終端機確認 node --version 有結果。macOS 上用 nvm 等工具裝的 Node.js，圖形介面的 App 可能找不到；把設定裡的 "node" 換成完整路徑（終端機輸入 which node 查到的路徑；Windows 用 where node）。

工具沒有出現

確認 JSON 沒有寫錯（逗號、引號、Windows 路徑的 \\），再把 AI 工具完全關掉重開。也可以直接在終端機執行設定裡的指令（加上 --folder）， 看有沒有錯誤訊息；沒有錯誤時它會停在那裡等 AI 工具連線，按 Ctrl+C 結束。

「找不到工作資料夾」：--folder 寫的資料夾不存在，先建好資料夾或改成正確的路徑。

檔案存到哪裡

都在 --folder 指定的工作資料夾。AI 回覆裡的路徑是相對於工作資料夾的路徑；問它「列出工作資料夾裡的電路檔」就會用 list_files 列出來。

# 兩塊板的大電路多給時間（子專案 54）設計規格

- 日期：2026-11-02
- 狀態：完成（PR #86，已發布）
- 出處：使用者 2026-11-02 要用 MCP 把課本圖 8-8（十進制加法器顯示電路）接成麵包板（面積最小、開關照順序、線只走水平垂直、不交叉、不跨過元件）。
  轉換試了 6 種接法都差 1–6 條線；使用者選「改進佈線器，讓這類大電路接得完」。

---

## 1. 問題

圖 8-8 有兩顆 74LS83、74LS08、74LS32、兩顆 74LS47 與兩個 7 段顯示器，一塊 EIC-1106 放不下，用兩塊左右貼在一起。
轉換的總時間固定 40 秒，佈線器每次都在時間到時停下，差 1 條。量測（一次跑一件）：40 秒差 1 條、**90 秒排完（257 條線）**。

## 2. 改變

- 轉換走到「兩塊 EIC-1106」那一步時，沒有指定總時間就多給 50 秒（總共 90 秒）。一塊板就排得完的電路不受影響。
- 轉換對話框的說明與 MCP `logic_to_breadboard` 的說明寫上「用到兩塊 EIC-1106 時最多一分半鐘」。
- 範例「十進制加法器顯示（圖 8-8）」：十位直接顯示修正訊號 C = C4 + S4·S3 + S4·S2
  （圖上是兩顆 74LS83 的進位 OR 起來，對所有輸入結果都一樣，少一個 OR 閘）。
- 量測（`npm run bench:convert`）加上圖 8-8；兩塊板的量測時間上限改成 100 秒。

## 3. 不做

- 讓佈線器本身更快或換演算法（這次只調時間分配）。
- 接不完時把部分結果存起來讓人補線（規則不允許斜線、交叉線當成暫時的接法）。

## 4. 測試

- 兩塊板時第一種擺法分到的排線時間超過 40 秒；指定總時間時照指定的（假的佈線，不用真的等）。
- 範例：100 組 BCD 數字 A + B 的十位、個位都對。
- 量測：圖 8-8 兩塊 EIC-1106 排完；用新的 MCP 伺服器實際轉換：257 條線、檢查沒有問題、256 種輸入全部一致。

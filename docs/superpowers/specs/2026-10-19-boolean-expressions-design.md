# 輸入布林式產生題目與麵包板（子專案 35）設計規格

- 日期：2026-10-19
- 狀態：已完成（使用者 2026-10-19 看過整理說「開始做」）
- 出處：`docs/ideas/backlog.md`「布林式」；使用者 2026-10-19：要的是「能直接有電路板上的布線可以照著接」，可以化簡。

---

## 1. 為什麼做

老師常直接給布林式（例如 `X = AB + A'C`）。現在要先自己算真值表、填題目，才能產生邏輯圖、轉成麵包板。
這次讓使用者**打布林式 → 化簡、產生邏輯圖 → 轉成麵包板並佈線 → 照接線清單插線**，中間都可以停下來看。

## 2. 目標、不做

**目標**

1. 邏輯圖畫面的「題目」分頁可以用布林式建立題目（還沒有題目時），或用布林式改寫題目（已經有題目時；可以 Undo）。
2. 一次可以輸入好幾行，每行一個輸出。
3. 建立題目後，用現有的「化簡與產生邏輯圖」顯示化簡結果（積項和、和積、只用 NAND、只用 NOR）。
4. 「化簡與產生邏輯圖」多一個按鈕「產生並轉成麵包板…」：產生邏輯圖後直接打開「轉成麵包板」的設定視窗，按「轉換」就自動佈線。
5. MCP 的 `task_set` 也可以直接給布林式。

**不做**

- 照式子原樣畫、不化簡（使用者說可以化簡）。
- 在自己畫的邏輯圖上顯示每個輸出的布林式（題目分頁已經顯示題目的化簡結果）。

## 3. 寫法

```
X = AB + A'C
Y = (A + B)'C
```

- 每行 `輸出名稱 = 式子`。名稱規則和題目一樣（英文字母開頭，英數與底線，最多 8 個字）。
  沒寫 `名稱 =` 的行：只有一行時叫 `F`，好幾行時依序叫 `F1`、`F2`…。空白行略過。
- 變數：**一個英文字母，後面可以接數字**（`A`、`B`、`A1`、`x2`）；大小寫不同。所以 `AB` 一定是 `A` 和 `B` 相乘，`A1B` 是 `A1` 和 `B`。
- 運算（優先順序由高到低）：
  1. 反相：後面加 `'`（也接受 `’`，從文件複製時常見）；或前面加 `!`、`~`、`¬`。例如 `A'`、`(A + B)'`、`!A`。
  2. AND：直接連在一起，或用 `*`、`·`、`⋅`、`&`、`∧`。
  3. XOR：`⊕` 或 `^`。
  4. OR：`+`、`|`、`∨`。
- 括號 `( )`；常數 `0`、`1`；空白不影響（`A B` 等於 `AB`）。
- 輸入：所有行用到的變數，**依字母排序**（`A`、`B`、`C`…；`A2` 在 `A10` 前面），第一個是最高位元；最多 6 個（和題目的上限一樣）。
- 錯誤用白話說明位置，例如「第 1 行第 9 個字：括號沒有關起來」「第 2 行：要寫成『輸出名稱 = 式子』」，
  其他限制沿用題目的訊息（輸入太多、名稱重複、名稱同時是輸入和輸出…）。

## 4. 做法

- `src/logic/expression.ts`（新，純函式）：讀布林式（語法樹）、算出真值表建立題目（`TruthTask`，用 `createTask`）。
- 題目分頁（`TaskTab`）：
  - 沒有題目時：在「輸入名稱 / 輸出名稱」下面多一個「或用布林式建立」：多行文字框（`aria-label` 布林式）、按鈕「用布林式建立題目」、寫法提示、錯誤訊息。
  - 有題目時：「改名稱」旁邊多一個「布林式…」，打開同樣的欄位，按「用布林式改寫題目」取代題目（進 Undo）。
  - 「化簡與產生邏輯圖」多一個按鈕「產生並轉成麵包板…」：做「產生邏輯圖」，再呼叫現有的 `openConvert()`。
- MCP：`task_set` 多一種用法 `expressions`（字串，好幾行用換行分開），和其他三種用法只能選一種；設定說明頁「第一次可以怎麼問」加一個布林式的例子。

## 5. 測試

- 單元：寫法（AND 的各種寫法、反相的前後寫法、XOR、括號、常數、空白、多行、沒寫名稱的行、`A1B`）、優先順序、
  真值表（輸入 A B C 時，`X = AB + A'C` 的 1 在第 1、3、6、7 列）、輸入排序、每一種錯誤的訊息；MCP `task_set` 的 `expressions`。
- 端對端：在題目分頁輸入 `X = AB + A'C` → 建立題目 → 化簡結果是 `AB + A'C` → 「產生並轉成麵包板…」→ 轉換 → 「和題目比對」全部一致。

## 6. Claude 做的決定（看規格時可以改）

- 布林式放在「題目」分頁（建立題目的地方），不另開新的畫面。
- 沒寫名稱的輸出叫 `F` / `F1`、`F2`…。
- 變數是一個字母加數字；XOR 也支援（課本常見）。
- 「產生並轉成麵包板…」會打開設定視窗，不直接轉換（還要選開關接 5V 或 GND、指撥開關或按鈕）。

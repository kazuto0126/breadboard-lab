# 匯流排（子專案 66）設計規格

- 日期：2026-11-14
- 狀態：完成（PR 合併時一起發布）
- 出處：使用者 2026-11-14 從代辦事項選「匯流排」，並決定：真的多位元訊號（一條粗線代表好幾個訊號，有「拆開」「合起來」元件，
  可以接到自訂方塊的多位元腳）；自訂方塊的 A0、A1、A2、A3 這種腳自動合成一個 A[3:0] 腳；主圖的輸入端、輸出端先不做多位元。

## 1. 元件與線

- 新元件「合起來」`MERGE`（width 2–8，預設 4）：左邊 width 個一位元輸入（由上到下是第 0 位到第 width − 1 位），右邊一個匯流排輸出。
- 新元件「拆開」`SPLIT`（width 2–8）：左邊一個匯流排輸入，右邊 width 個一位元輸出（由上到下第 0 位起）。
- 線的位元數就是來源腳的位元數；只能接到位元數一樣的腳（不一樣時說明「4 位元的匯流排只能接到 4 位元的腳」）。
  匯流排畫成粗線，旁邊寫位元數（/4）；模擬時寫目前的值（十進位）。
- 寬度改小時，接到不存在的腳或位元數不合的線拿掉。

## 2. 自訂方塊的多位元腳

- 方塊裡的輸入端（輸出端）名稱是「同一個名字 + 數字」，而且數字剛好是 0、1、…、n − 1（n ≥ 2）時，合成一個 n 位元的腳，腳名寫 A[3:0]；
  第 k 位是 A{k}。腳的位置在那一組最上面的那個輸入端（輸出端）的位置。其他的腳照舊一個訊號一個腳。
- 新做的方塊（網頁「包成方塊」、MCP）都會合成；子專案 65 存的檔案裡的方塊（沒有 `busPins`）照舊不合成，線不會亂掉。
- 包成方塊時，外面一個一個的訊號接到多位元腳：自動加一個「合起來」（輸入）或「拆開」（輸出）元件接好。
- 改方塊回到上一層時：腳照名稱接回去（多位元腳看名字，例如 A）；位元數變了的線拿掉。

## 3. 計算

- 展開（子專案 65 的 `flattenDiagram`）改成以「位元」為單位：每條匯流排線拆成 n 條一位元的連接，經過「合起來」「拆開」與方塊的多位元腳，
  最後只剩一位元的線。真值表、時序表、模擬、布林式、轉成麵包板、比對都不用改。
- 匯流排的值：展開時記下每一位對到的訊號（`訊號[k]`），畫布用來寫十進位的值。

## 4. 網頁

- 元件庫多「合起來（匯流排）」「拆開（匯流排）」；屬性面板可以改位元數（2–8）。
- 方塊的多位元腳寫 A[3:0]；匯流排粗線。

## 5. MCP

- `logic_set` 可以用 `{ kind: "MERGE" | "SPLIT", width }`，方塊預設合成多位元腳（`busPins: false` 可以關掉）；`logic_wrap_block` 一樣會自動加合起來 / 拆開。
- 說明與設定說明頁同步。

## 6. 測試

- 單元：腳的合成（A0–A3、不連號不合成、舊檔不合成）；合起來 → 拆開直通；4 位元加法器：兩個 4 位元匯流排接到用全加器方塊做的方塊，真值表正確；
  位元數不合的線拒絕；包成方塊自動加合起來 / 拆開且真值表不變；讀檔檢查；轉成麵包板比對一致；MCP。
- e2e：放合起來、拆開，接成匯流排，真值表正確；畫面上是粗線。

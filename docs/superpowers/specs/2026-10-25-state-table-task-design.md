## 1. 目的

時序電路的設計題通常這樣出：給一張狀態表（現在狀態、輸入 → 下一個狀態、輸出），學生要寫出正反器的激勵表、
用卡諾圖化簡出每個正反器輸入的布林式，再畫出電路。子專案 24、25 已經能從真值表題目產生組合電路；
這次讓「題目」分頁也能寫狀態表，按一下就產生用單顆正反器（子專案 51）做的時序電路，並列出化簡後的式子讓學生對答案。

## 2. 狀態表題目

- 狀態固定叫 S0、S1、…（2–8 個），用二進位編碼：S0 = 0…0、S1 = 0…1，依此類推。**S0 是重設（上電）後的狀態**。
  正反器的個數是能編出所有狀態的最少個數（2 個狀態 1 顆、3–4 個 2 顆、5–8 個 3 顆），狀態位元叫 Q0（最低位元）、Q1、Q2。
- 輸入 0–2 個、輸出 0–4 個（名稱規則和真值表題目一樣；不能用 Q0–Q2、D0–D2、J0–J2、K0–K2，那是正反器用的名稱）。
- 每一列是「現在狀態 × 輸入組合」（狀態由小到大，同一個狀態裡輸入照二進位從全 0 到全 1）：
  - 下一個狀態：S0–S(n−1) 或 X（不在乎）。
  - 每個輸出：0 / 1 / X。輸出寫在每一列，所以 Moore（輸出只看狀態，同一個狀態每列都一樣）和 Mealy（也看輸入）都能寫。
- 正反器：D 型（預設）或 JK。
- 存在邏輯圖的 `stateTask` 欄位（和真值表題目 `task` 一樣跟著檔案、Undo）。兩種題目可以同時存在，題目分頁上方切換「真值表題目 / 狀態表題目」。

## 3. 化簡

- 變數是 Q(k−1)…Q0 再接著輸入（Q 在前、第一個是最高位元）。沒用到的狀態編碼（例如 3 個狀態時的 11）整列都是不在乎。
- D 型：Dk = 下一個狀態的第 k 位元。
- JK：用激勵表，Q 是 0 時 J = 下一位元、K = X；Q 是 1 時 J = X、K = 下一位元的反相。
- 輸出照列化簡。全部用子專案 25 的化簡（積項和、不同式子共用相同的項）。

## 4. 產生的電路

- 時脈 CLK、每個狀態位元一顆 DFF 或 JKFF（CLK 都接時脈）、題目的輸入端、化簡後的 AND–OR 邏輯、題目的輸出端，
  再加上狀態位元的輸出端 Q(k−1)…Q0（看得到現在在哪個狀態）。
- 化簡結果用到 Qk' 時直接接正反器的 /Q，不另外放 NOT。
- 取代目前的邏輯圖（兩種題目都保留），可以 Undo；接著可以看時序表、波形、轉成麵包板（正反器兩顆合用一片 74LS74 / 76）。

## 5. 畫面（「題目」分頁）

- 上方切換「真值表題目」「狀態表題目」。
- 沒有狀態表題目時：狀態數、輸入名稱、輸出名稱、正反器（D / JK），按「建立題目」。
- 有題目時：表格每列寫「現在狀態（編碼）、輸入、下一個狀態（下拉選單）、輸出（點一下 0 → 1 → X）」；
  下面列出化簡後的式子（D1 = …、Z = …）、「產生電路」按鈕，和「刪除題目」。
- 不做：和自己畫的電路比對狀態表（自己畫的電路不知道哪顆正反器是哪個位元；用時序表檢查）、狀態圖、自訂狀態名稱與編碼。

## 6. MCP

- `state_task_set`：寫入（或 `clear: true` 刪除）狀態表題目：`states`、`inputs`、`outputs`、`flip_flop`（`D` / `JK`），
  `rows` 每列 `{ next, out }`（next 是 0–n−1 或 "X"；out 是每個輸出的 0 / 1 / "X"）。回覆列出狀態表與化簡後的式子。
- `state_task_to_diagram`：產生電路，取代檔案裡的邏輯圖，回覆化簡後的式子與從 S0 開始的時序表。
- 伺服器說明加上狀態表的流程；設定說明頁列出新工具。

## 7. 測試與驗收

- 化簡：2 位元上數計數器（沒有輸入）D0 = Q0'、D1 = Q1 ⊕ Q0 的積項和；JK 時 J0 = K0 = 1、J1 = K1 = Q0。
- 序列偵測（輸入 X、輸出 Z，Mealy）：產生的電路從 S0 開始，照輸入序列送脈衝，輸出和狀態表一樣。
- 3 個狀態時沒用到的編碼是不在乎；名稱規則與保留名稱。
- 檔案讀寫保留狀態表題目；MCP 兩個工具；端對端：建立計數器題目、產生電路、時序表數 0–3。

# 轉成麵包板時電源接最近的軌（子專案 34）設計規格

- 日期：2026-10-19
- 狀態：已完成（使用者 2026-10-19 看過規格說「好」）
- 出處：使用者 2026-10-19：「邏輯圖轉成電路版的部分，若需要接正極或負極讓線路以最近的正負極接線，
  以及若電源上已插有 5V 或 GND 則不需要另外拉線到另一條電源槽」；確認只改「轉成麵包板」，自己接的板子按 AI 佈線時照舊。

---

## 1. 現在的問題（2026-10-19 實際轉換範例看到的）

- **多拉電源軌之間的線**：轉換時把所有 5V（GND 一樣）當成同一個訊號串在一起，所以每條軌雖然已經插了 5V / GND 符號，
  佈線後還是多了軌對軌的線。多數決（MB-102）：`B+6 → T+6`、`B-5 → T-5`；EIC-1106 多 4 條。
- **沒有接最近的軌**：例如上半部的 `E48` 要接地，卻拉到下面的 − 軌 `B-48`。
- 原因在 `src/logic/toBreadboard.ts`「連線導線」：每個訊號的終端依序兩兩相接，5V 的終端包含每條軌上的 5V 符號。
- 轉換後的「AI 佈線（可移動 IC）」會把 IC 轉 180° 或搬到別的插孔區（例如 BCD 範例的 U1 轉了 180°、多數決在 EIC-1106 從第 2 區搬到第 1 區），
  所以「最近的軌」要在 IC 搬好之後才知道。

## 2. 要做到的

1. 轉換出來的麵包板，每一個要接 5V 的腳接到**離它最近的 + 軌**，要接 GND 的腳接到**最近的 − 軌**。
2. 用到的每一條電源軌都插一個 5V 或 GND 符號（代表電源直接接到這條軌）；**軌和軌之間不拉線**。沒用到的軌不插。
3. 「AI 佈線（可移動 IC）」搬動或轉向 IC 之後，電源腳仍然接到搬動後最近的軌（不是轉換時算的那條）。
4. 佈線前（手動接線版）與佈線後都符合 1、2；和邏輯圖、題目比對的結果不變（全部一致）。

**不改**：自己接的板子按「AI 標準佈線」或「AI 佈線（可移動 IC）」時，照舊保留使用者自己拉的軌對軌的線（使用者確認）。

## 3. 「最近」的算法

- 腳所在的導通群組（同一排 5 個孔）和每一條該極性的電源軌，比**上下距離**（列的 y 差，取群組裡最近的孔）；只看同一塊板。
- 同樣近時取上面的軌（固定，結果可以重現）。
- MB-102：上半部（A–E）→ 上面的 `T+` / `T-`；下半部（F–J）→ 下面的 `B+` / `B-`。
- EIC-1106：每個插孔區用它上下兩條軌（例如第 2 區上半部 → `P3`、下半部 → `P4`），不會跨過別的插孔區。
- 軌的極性看名稱最後一個字（`+` / `-`），來自板子的版型資料，不寫死軌的名稱。
- 版型：MB-102 由上到下 `T-`、`T+`、上半部、下半部、`B+`、`B-`；EIC-1106 由上到下 P1、P2、第 1 區、P3、第 2 區、P4、第 3 區、P5（每條 `+` 在上、`-` 在下），
  P1 離每個插孔區都比 P2 遠，所以不會被選到。

## 4. 做法

- **核心函式**（`src/core/`，不碰瀏覽器 API）：
  - 找最近的軌：給一個孔與極性，回傳最近的該極性電源軌（第 3 節的規則）。
  - 重新接電源：給一個電路，把「腳的群組 ↔ 插了 5V / GND 符號的軌」這種連線改接到最近的同極性軌；
    最近的軌還沒有符號時補一個符號（編號接著現有的 V、G），沒有任何連線的符號拿掉。其他連線與元件不動。
    回傳新的電路，以及補上 / 拿掉了哪些符號。
- **轉換**（`toBreadboard`）：5V / GND 不再串在一起，每個要接電源的腳直接拉一條連線到最近的軌，只在用到的軌插符號。
- **可移動 IC 的佈線**：佈線設定多一個選項（預設關閉），打開時每個候選位置在佈線前先「重新接電源」（在檢查「每支腳接到的腳不變」之後），
  最後的結果也是重新接過的；「轉成麵包板」（網頁與 MCP 的 `logic_to_breadboard`）佈線時打開，其他時候都關閉。
- **佈線結果**多一個可有可無的欄位：補上 / 拿掉的 5V、GND 符號；套用佈線結果時一起加上 / 拿掉（沒有這個欄位時和現在完全一樣）。
- 佈線結果仍一定經過 `checkRoutingLegality`。

## 5. 測試

- 單元：最近的軌（MB-102 上下半部、EIC-1106 三個插孔區、同樣近時取上面）；重新接電源（改接、補符號、拿掉沒用的符號、訊號線不動）。
- 轉換：多數決（MB-102、EIC-1106）、BCD 範例（共陽極、共陰極）、只用 NAND、按鈕輸入、有上 / 下拉電阻：
  轉換後與佈線後都沒有兩端都在電源軌的線；每條接到電源軌的線都接最近的同極性軌；和邏輯圖比對全部一致。
- 可移動 IC：IC 被轉 180° 或搬到別的插孔區時，電源腳接到新的最近的軌。
- 選項關閉（一般的 AI 佈線）時，自己拉的軌對軌的線照舊保留（現有測試不變）。
- 端對端：轉換範例後，板上沒有軌對軌的線。

## 6. Claude 做的決定（看規格時可以改）

- 只在用到的軌插 5V / GND 符號；EIC-1106 原本固定插 6 個，改成用到幾條插幾條；IC 搬動後跟著補上 / 拿掉。
- 同樣近時取上面的軌。
- 可移動 IC 用「每個候選位置先重新接電源」做到第 2 點的 3，不另外再佈線一次；IC 照樣可以轉 180° 或換插孔區。
- 新補的符號放在那條軌左邊第一個空的孔（和現在一樣靠左，從第 3 欄開始找）。

## 1. 要做什麼

電路（麵包板＋邏輯圖＋題目，和「匯出 JSON」同一個檔案）壓縮後放在網址 `#` 後面。點開連結就在網頁上看到那個電路，不用下載、匯入檔案。
用途：AI 透過 MCP 做完電路給一個連結；同學之間分享；老師把範例電路貼在公告。

## 2. 連結的格式

- `https://kazuto0126.github.io/breadboard-lab-site/#c=<資料>`；資料是電路檔 JSON 用 deflate（raw）壓縮後的 base64url。
- `#` 後面的內容不會送到伺服器（網站只是靜態頁），電路只在點開的人的瀏覽器裡。
- 網頁從 http(s) 開啟時用目前網址（不含 `#`）當開頭；離線版（file://）用線上版的網址。
- 連結超過 8000 個字時提醒：有些通訊軟體會截斷很長的網址，大電路改用「匯出 JSON」。

## 3. 網頁

- **檔案 → 複製連結**：把目前的電路做成連結，複製到剪貼簿，提示字數（太長時加上提醒）。
- **開啟連結**：網頁打開時（以及網址的 `#` 改變時）看到 `#c=`，解開後：
  - 目前的電路沒有未儲存的修改：直接開啟（「已從連結開啟「名稱」」）。
  - 有未儲存的修改（麵包板或邏輯圖）：先問「要用連結的電路取代目前的電路嗎？」（取消／先儲存／開啟連結），因為開啟後 Undo 回不到目前的電路。
  - 解不開或不是電路檔：提示「連結裡的電路讀不出來」，不動目前的電路。
  - 處理完把網址的 `#c=…` 拿掉（重新整理時不會再開一次、蓋掉之後的修改）。

## 4. MCP

- 新工具 `share_link`：給電路檔，回傳連結與字數（太長時加上提醒）。
- 伺服器說明：做完電路可以用 `share_link` 給使用者一個連結；`logic_to_breadboard` 的說明也提到。
- 設定說明頁的工具表加上 `share_link`。

## 5. 不做

- 短網址服務（要另外的伺服器，也會把電路送到別人的伺服器）。
- 連結裡放「已接好的導線」勾選清單（接線清單的勾選狀態只留在自己的瀏覽器）。

## 6. 驗收

- 壓縮再解開後電路檔一樣；`#c=` 以外的網址、壞掉的資料、不是電路檔都說明原因。
- 網頁：複製連結後在新分頁打開，看到同一個電路；有未儲存的修改時先問；開啟後網址沒有 `#c=`。
- MCP：`share_link` 回傳的連結解開後是那個檔案的電路；工具數 20。

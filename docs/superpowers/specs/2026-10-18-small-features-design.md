## 27. 只用 NOR

- 「轉成麵包板」的閘的種類多一個「只用 NOR（74LS02）」，和只用 NAND 一樣：拆好的單元全部換成 2 輸入 NOR 再化簡
  （反相兩次抵消、相同的閘只做一次、拿掉沒用到的閘）。
- 換法是 NAND 的對偶：NOT = NOR(x, x)、OR = NOT(NOR)、AND = NOR(NOT a, NOT b)、NAND = NOT(AND)、XOR = NOR(NOR(a, b), AND(a, b))。
- `ConvertOptions.gates`：`'direct' | 'nand' | 'nor'`；MCP 的 `logic_to_breadboard` 也可以選。

## 28. 轉向的加強

- **鏡射**：閘、IC 方塊可以左右翻轉（`flip: true`）。翻轉後輸入在右、輸出在左，但腳的上下順序不變（IC 方塊的 A1 還是在上面）。
  翻轉和轉向可以一起用（先翻轉再轉）；快捷鍵 M，屬性面板「鏡射」按鈕。
- **放置時先轉好**：點元件庫準備放置時按 R（轉向）或 M（鏡射），預覽跟著變，放下去就是那個方向。
- **輸入端、輸出端、5V / GND 也能轉**：四個角度與鏡射都可以；名稱、數值一律正著寫。7 段顯示器仍然不轉。
- 檔案：`flip` 只有可以轉向的元件能有；讀檔檢查。

## 29. 便條

- **邏輯圖上的便條**：和麵包板的便條一樣（文字、四種顏色、隨文字長度變大、拖曳移動、可以指向一個元件）。
  邏輯圖的元件庫多一張「便條」卡片（拖到畫布上，或點一下再點畫布）；存在邏輯圖資料的 `notes`（格子座標），
  進邏輯圖的 Undo；選取後屬性面板改文字、顏色、指向、刪除。
- **麵包板便條指向孔位**：指向可以是元件，也可以是一個孔（輸入孔位名稱，例如 `F12`、`2-A5`）；畫一條線指到那個孔。
  `Note.targetHole?: GridPoint`（和 `target` 只能有一個）。

## 30. 輸入用按鈕

- 「轉成麵包板」的輸入多一個選擇：「指撥開關」（預設）或「按鈕」。按鈕每個輸入一顆，跨過凹槽放在開關原本的位置；
  一側接 +5 V（或 GND），另一側接 IC 的輸入。
- 按鈕可以取名（屬性面板「名稱」，畫在按鈕旁），依名稱對照邏輯圖 / 題目時，輸入可以對應到按鈕：比對時那一列是 1 就當成按住。
- 模擬：放開的按鈕和指撥開關一樣當成理想開關（一側是 0 / 1、另一側浮接時，浮接端當成相反的電位）；沒有上 / 下拉電阻時檢查給警告。
- 點不一致的一列：撥好開關、按住對應的按鈕並開始模擬。

## 31. 題目產生邏輯圖的其他形式

- 題目分頁的「化簡」多一個形式選擇：**積項和（AND–OR）**、**和積（OR–AND）**、**只用 NAND**、**只用 NOR**。
  - 和積：用 0 的列化簡（X 一樣可以幫忙），布林式寫成 `(A + B)(A' + C)`；產生 OR–AND 圖。
  - 只用 NAND：積項和改成 NAND–NAND（反相也用 NAND，兩個輸入接同一個訊號）；只用 NOR：和積改成 NOR–NOR。
- 多個輸出一起化簡：挑最少覆蓋時，同樣好的選擇優先用別的輸出已經用過的項（共用更多 AND / OR）。
- 產生的圖和題目比對一定全部一致。

## 32. 7 段顯示器的加強

- **共陰極**：新增 74LS48（BCD 轉 7 段，高電位有效）與共陰極顯示器 `7seg-cc`；「轉成麵包板」可以選顯示器種類
  （共陽極 + 74LS47，或共陰極 + 74LS48）。模擬、檢查、全暗的原因都支援共陰極。
- **小數點**：邏輯圖的顯示器多一個 DP 輸入（在 B 和 C 中間那一列，可以不接，不接就不亮）；DP = 1 時點亮小數點，
  真值表與比對寫成「5.」；轉成麵包板時 DP 經過電阻接到顯示器的 dp（共陽極時先經過一個反相器）。
- **單獨點亮某一段**：顯示器可以切到「每段直接控制」：8 個輸入 a–g、dp，1 就點亮那一段；真值表寫亮的段
  （剛好是數字的字形時寫數字）。轉成麵包板時不用解碼 IC，每段經過電阻接到顯示器（共陽極時先經過反相器）。
- **題目的輸出可以是 7 段顯示器**：輸出欄可以設成顯示器，格子是 0–15 或 X；和邏輯圖、麵包板比對；
  產生邏輯圖時拆成 D、C、B、A 四個位元各自化簡，再接到顯示器。
- **多位數**：轉成麵包板時顯示器最多 2 個，佈線測試能接完的話放寬到 4 個（EIC-1106）。

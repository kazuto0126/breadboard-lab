# 直線導線（子專案 6：手動拉斜線、拖曳端點）設計規格

- 日期：2026-10-10
- 狀態：設計已確認，實作中
- 來源：使用者 2026-10-10 的新需求第 0、4 項（第 1、2 項的新自動佈線標準是子專案 7，見文末）
- 需求文件：第七章（接線）、第二十三章（操作）

---

## 0. 目的

實體麵包板上的跳線是一段直的線，插在兩個孔上。現在手動接線會自動繞路、中途轉彎，和學生手上的跳線不一樣。
這個子專案把手動接線改成「兩個孔之間的一條直線」（可以是斜的），並且可以拖曳線的端點改接到別的孔。

## 1. 決定

| 項目 | 決定 |
|---|---|
| 手動新拉的線 | 起點到終點的一條直線，任何角度都可以；不再自動繞路。要轉彎就拉兩條線 |
| 一孔多線 | 手動接線可以有多條線接在同一個孔（使用者決定：「一孔一線」只限自動佈線）。Check Circuit 不再報「同時插了多條導線」 |
| 元件腳的孔 | 仍然不能接線（實物插不進去）：起點、終點不能是元件腳或被元件本體蓋住的孔 |
| 經過元件或和別條線重疊 | **不允許**（使用者決定）。拉線時預覽變紅，放開不會建立；Check Circuit 也會把既有的違規標成錯誤（例如之後把 IC 移到線下面） |
| 交叉 | 兩條線交叉成 X 形可以（只在一點相交）；「重疊」是兩條線共線而且共用一段長度 |
| 拖曳端點 | 選取一條線後，兩端出現可以拖曳的圓點；拖到別的孔就改接，線變成直線。規則同上 |
| 自動佈線 | 這個子專案不改：仍然輸出正交、可以轉彎的線（子專案 7 再改成新標準） |
| 舊存檔 | 已經轉彎的線維持原樣、照常顯示與檢查；不自動拆開（拆開會讓轉彎處的孔通電，電路意思就變了） |

### 1.1 「經過」的定義

- 線段用全域格子座標（`latticeOf`）計算；每個孔看成以孔為中心、邊長 0.9 格的正方形，線段穿過這個正方形就算「經過」這個孔。
  斜線從兩個孔的正中間對角穿過時不算經過（正方形之間留 0.1 格）。
- 兩端的孔不算經過。
- 經過下列孔就是違規（`WIRE_THROUGH_OBSTACLE`）：有元件腳、被元件本體蓋住、或是別條線的端點（和現在的規則一樣）。
- 重疊（`WIRE_OVERLAP`）：任兩條線的線段共線、重疊部分長度大於 0。舊的轉彎線拆成一段一段的直線來比。
  兩條都是舊的轉彎線時沿用現在的規則（以格點判斷），自動佈線的合法性檢查不受影響。

## 2. 資料

- `Wire` 加一個選填欄位 `straight?: true`。直線導線的 `path` 固定是 `[start, end]` 兩點。
- 沒有 `straight` 的線是舊的路徑導線（自動佈線的輸出、舊存檔），`path` 仍然是相鄰格點的序列。
- 存檔格式不升版本：直線導線多寫一個 `"straight": true`；讀檔時 `straight` 為 true 就忽略 `path`，改成 `[start, end]`。

## 3. 畫面

### 3.1 拉線

- 從孔按下拖曳：起點可以是任何孔，只要不是元件腳、沒被本體蓋住（可以是已經有線的孔）。
- 拖曳中顯示一條從起點到游標所在孔的直線預覽：
  - 合法：用導線預設顏色。
  - 終點不合法（元件腳、本體、和起點同一孔、不同的 Board Group）或經過障礙、和別條線重疊：預覽變紅。
- 放開：合法就建立一條直線導線（Undo 一步「接線 wN」）。不合法就不建立，跳出提示，例如：
  - 「直線不能經過元件或其他導線的端點（經過 U1 的腳 E12）」
  - 「直線不能和導線 w3 重疊」
  - 「終點不能是元件腳或被元件蓋住的孔」
- 已經有線的孔：按在線的端點上，若這條線**沒有被選取**，就當成按在孔上（可以從這裡拉出新線）；按在線身上則是選取這條線。

### 3.2 拖曳端點

- 選取一條線（任何線，包括自動佈線的線與舊的轉彎線）後，兩端各有一個圓形把手（`data-wire-handle="start" | "end"`），觸控時點擊範圍至少 44 px。
- 拖曳把手：另一端固定，顯示從固定端到游標所在孔的直線預覽，合法規則同 3.1。
- 放開在合法的孔：這條線改成直線導線，端點換成新的孔；`source` 變成 `manual`，顏色、ID 不變；Undo 一步「移動導線 wN 的端點」。
- 不合法或放回原位：不改變，不合法時跳出提示。
- 模擬中、佈線計算中不能拖曳（沿用 `guardEdit`）。

## 4. 其他受影響的地方

| 地方 | 改法 |
|---|---|
| 檢查電路 | 1.1 的經過與重疊規則；不再報一孔多線；直線導線的路徑檢查只看兩端：不同孔、在板上、同一個 Board Group |
| 佔用（`buildOccupancy`） | 直線導線經過的孔算進 `wirePaths`（給「空孔」判斷、孔的說明「導線 wN 從上面經過」） |
| 統計與 Routing Score | 直線導線長度 = 兩端的直線距離（格），轉彎 0；交叉用線段相交計算 |
| 接線清單、導線說明 | 長度用同一個函式；直線導線顯示「直線 · N 格」，四捨五入到小數一位 |
| 錯誤解說的建議導線 | 改成兩個孔之間的直線；挑孔時避開會經過障礙的組合；找不到就只給文字 |
| 手動接線路徑規劃 `planWirePath` | 不再使用，連同測試刪掉 |

## 6. 測試

- 單元：`cellsUnder`（水平、垂直、斜線、對角從中間穿過不算、跨板）；線段重疊與交叉；直線導線的檢查（經過 IC、經過別條線端點、重疊、交叉不算錯、一孔多線不算錯）；
  存檔讀寫 `straight`；`straightWireProblem` 的每種原因；`moveWireEnd`；統計（長度、轉彎、交叉）；錯誤解說的建議是直線且不經過障礙（現有「照著做錯誤會消失」的測試照樣通過）。
- Store：拉線建立直線、不合法不建立；拖曳端點、Undo。
- 端對端：拉一條斜線（存檔裡 `straight: true`、兩點）；拉一條經過 IC 的線被拒絕；選取線後拖曳端點改接；現有驗收流程的手動接線改成檢查直線。

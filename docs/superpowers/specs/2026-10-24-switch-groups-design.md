# 兩個 4 位元開關依 IC 分組（子專案 45）設計規格

- 日期：2026-10-24
- 狀態：完成（PR #70 已合併並發布到線上版）
- 出處：`docs/ideas/backlog.md`「兩個開關依 IC 分組」；使用者 2026-10-24 選了「1 和 3」，這是 3（小的先做）。

## 1. 要做什麼

子專案 38 起，加上 / 下拉電阻、輸入超過 4 個時，轉換會試「開關拆成兩個 4 位元」的擺法，原本照名稱分（前 4 個在 SW1、其他在 SW2）。
改成依「哪顆 IC 先用到」分：IC 依放在板上的順序（邏輯閘、IC 方塊、顯示器的解碼 IC），每個輸入看第一次被哪顆用到，同一顆 IC 用到的輸入盡量在同一個開關；
沒有 IC 用到的（只接 LED 等）排在最後；每個開關裡照名稱排。電阻的編號仍然依輸入的名稱順序（R1 是 A 的電阻）。

## 2. 驗收

- 分組規則的單元測試；實習七 C（加下拉電阻）SW1 是 U1 用到的 C、D、E、F。
- `npm run bench:convert` 不變差：實習七 C（加下拉電阻）58 → 57 條線、總長 303 → 283；其他電路不變（沒有用到兩個開關）。
- MCP 沒有新的參數（轉換的行為一樣跟著改）。

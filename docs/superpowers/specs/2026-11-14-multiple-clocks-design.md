# 多個時脈（子專案 64）設計規格

- 日期：2026-11-14
- 狀態：完成（PR 合併時一起發布）
- 出處：使用者 2026-11-14 選代辦事項第 2 項「時序電路的其他功能」的最後一部分；多個時脈選「各自獨立、一次送一個」：
  可以放好幾個時脈（CLK、CLK2…），各自接不同的正反器；時序表選一個時脈送脈衝，或照使用者寫的順序送（例如「CLK CLK CLK2」）。

## 1. 邏輯圖

- 一張圖最多 4 個時脈（以前 1 個）。第一個預設名稱 CLK，之後 CLK2、CLK3、CLK4（名稱可以改，不能重複，和其他名稱一樣）。
- 每個時脈的「脈衝」按鈕（畫布上的按鈕、屬性面板）只送那一個時脈。
- 狀態表題目（子專案 52、53、62）照舊只用一個時脈；比對時圖上有好幾個時脈會說明。

## 2. 時序表與波形

- `sequenceTable(d, pulses, values, seed, order)`：order 是時脈名稱的清單，照順序一直重複（例如 CLK、CLK2 → 第 1 次 CLK、第 2 次 CLK2、第 3 次 CLK…）。
  沒給時只有一個時脈就送它；有好幾個時是名稱排第一個的那個（我的決定：和以前一樣「一次一個時脈」，要輪流就用自訂順序）。
- 每一列記下送了哪個時脈（第 0 列沒有）。表格在有好幾個時脈時多一欄「時脈」，第一欄改叫「第幾次」。
- 網頁「時序表」分頁在有好幾個時脈時多一列選擇：每個時脈各一個按鈕，加上「自訂順序」輸入框（空白、逗號隔開的名稱）；名稱打錯時說明。
- 波形每個時脈一條線，只有送了那個時脈的格子畫脈衝。

## 3. 轉成麵包板

- 每個時脈一個時脈元件 CLK1、CLK2…，名稱（labels）寫邏輯圖時脈的名稱；都放在開關前面，各自靠近用到它的子電路。
- 依名稱比對（子專案 22、46）：邏輯圖的時脈對應到名稱一樣的時脈元件；只有一個時脈、麵包板上也只有一個時脈元件時不看名稱（和以前一樣）。
- 比對時有好幾個時脈就輪流送（CLK、CLK2…一直重複），每個時脈都比得到。

## 4. MCP

- `logic_set` 可以放好幾個 CLOCK 節點。
- `logic_truth_table` 多一個 `clocks` 參數（時脈名稱的清單，照順序重複送）；時序表與文字波形每個時脈一條。
- 工具說明、伺服器說明與設定說明頁同步。

## 5. 測試

- 單元：兩個時脈各接一顆 DFF 計數，指定順序後各自只在自己的脈衝變；預設送第一個；名稱打錯；
  波形每個時脈一條；轉成麵包板有兩個時脈元件、名稱對、比對一致；狀態表比對有兩個時脈時說明；MCP clocks 參數。
- e2e：放兩個時脈，時序表選 CLK2 與自訂順序。

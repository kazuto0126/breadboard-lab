# 自訂方塊（子專案 65）設計規格

- 日期：2026-11-14
- 狀態：完成（PR 合併時一起發布）
- 出處：使用者 2026-11-14 從代辦事項選「自訂方塊、匯流排」，並決定：
  - 框選一段邏輯圖「包成方塊」（穿過框的線變成方塊的腳），之後從元件庫放更多個；可以打開方塊看裡面、改裡面，每個用到的地方一起變；
  - 方塊跟著這個檔案存（要在別的檔案用就複製貼上）；
  - 這次只做方塊，匯流排之後另外一個子專案；
  - 方塊裡可以再放自訂方塊（例如半加器 → 全加器 → 4 位元加法器），不能用到自己。

## 1. 資料

- `LogicDiagram.blocks?: CustomBlock[]`：這個檔案的自訂方塊定義。
  `CustomBlock = { id, name, nodes, wires }`：裡面是一張小邏輯圖；裡面的**輸入端是方塊的輸入腳、輸出端是輸出腳**，
  腳的順序照輸入端 / 輸出端在圖上的位置由上到下（y，再 x），腳名就是輸入端 / 輸出端的名稱。
- 新的節點種類 `CUSTOM`：`{ kind: 'CUSTOM', block: 定義的 id, inputs: 輸入腳數, outputs: 輸出腳數 }`（腳數存在節點上，畫圖、算位置不用查定義；定義改了腳時一起更新）。
- 方塊名稱和輸入端名稱同一套規則（英文字母開頭、英數字與底線、最多 8 個字），同一個檔案裡不能重複。
- 方塊裡可以放：邏輯閘、IC 方塊（含正反器、計數器）、5V / GND、其他自訂方塊、輸入端、輸出端；不能放時脈與 7 段顯示器
  （時序方塊的 CLK 從方塊的輸入腳接進來）。不能直接或間接用到自己。

## 2. 計算：展開

- `flattenDiagram(d)` 把每個 CUSTOM 節點換成它裡面的元件（id 前面加 `方塊節點 id/`，巢狀時一層一層加），
  接到方塊輸入腳的線改接到裡面用到那個輸入端的腳，從方塊輸出腳出去的線改從裡面接到那個輸出端的訊號出去；沒接的腳就是沒接。
- 真值表、時序表、模擬、布林式、迴授判斷、轉成麵包板、依名稱比對、NAND / NOR 轉換都用展開後的圖（在各入口展開，結果有快取）。
- 模擬時方塊輸出腳的值（畫線的顏色、屬性面板）用展開後對應訊號的值。

## 3. 包成方塊

- 框選（或 Shift 點選）幾個元件 →「包成方塊」→ 輸入名稱（預設 B1、B2…）。
- 只能包閘、IC 方塊、5V / GND、自訂方塊；選到輸入端、輸出端、時脈、顯示器時說明（輸入端、輸出端留在外面，會自動變成方塊的腳）。
- 從外面接進來的線：同一個訊號只算一個輸入腳；腳名用來源輸入端的名稱，不是輸入端時是 I1、I2…。
  從裡面接出去的線：同一個訊號一個輸出腳；腳名用接到的輸出端名稱，沒有時是 O1、O2…；名稱重複時加數字。
- 腳的順序照來源 / 目的在圖上的位置由上到下。原來的元件換成一個方塊（放在原本的位置，重疊時往右下找空位），線接到方塊的腳；Undo 可以還原。

## 4. 放更多個、打開、修改

- 元件庫多一區「自訂方塊（這個檔案）」，列出每個方塊，點一下放置；沒用到的方塊可以刪除。
- 點兩下方塊（或屬性面板「打開方塊」）進到裡面編輯，畫布上方顯示「主圖 › B1」，按「回到上一層」回去；
  在裡面時真值表、時序表是這個方塊自己的，不能轉成麵包板（說明要回到主圖）。
- 回去時：腳照新的輸入端 / 輸出端重算，每個用到這個方塊的地方一起更新；腳名還在的線照名稱接回去，腳不見了的線拿掉。
  整次修改在主圖是一步 Undo。
- 存檔、自動儲存、匯出一律存主圖（在方塊裡時把正在改的內容一起存進去）。

## 5. MCP

- `logic_set` 多一個 `blocks` 參數（自訂方塊的定義：id、name、nodes、wires），節點可以用 `kind: "CUSTOM", block: "<id>"`。
- 新工具 `logic_wrap_block`（file、nodes：要包的元件 id、name）：和網頁的「包成方塊」一樣。
- `logic_truth_table` 照舊（用展開後的圖）；回覆列出檔案裡的自訂方塊與腳。說明與設定說明頁同步。

## 6. 測試

- 單元：展開（輸入腳、輸出腳、巢狀、沒接的腳、直接從輸入接到輸出）；半加器包成方塊後真值表不變；兩個半加器組成全加器（巢狀）；
  修改方塊後腳的增減與線的保留；讀檔檢查（用到自己、不存在的方塊、不能放的元件）；轉成麵包板與比對一致；MCP logic_set blocks、logic_wrap_block。
- e2e：框選兩個閘包成方塊、真值表不變、再放一個、點兩下進去改、回來後兩個都變。

## 7. 這次不做

- 匯流排（之後另外一個子專案）；跨檔案的方塊庫（複製貼上即可）；方塊的外觀自訂。

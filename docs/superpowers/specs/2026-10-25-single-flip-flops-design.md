# 單顆正反器元件（子專案 51）設計規格

## 1. 目的

課本畫同步計數器、移位暫存器時，畫的是一顆一顆的 D 或 JK 正反器（D、CLK → Q、/Q）。
子專案 46 只有整顆 IC 的方塊（74LS74 一個方塊有兩組正反器、8 隻輸入），畫起來和課本不像，兩組的腳也容易接錯。

## 2. 元件

- 元件庫「正反器與計數器」多兩個：**DFF**（D 型正反器）與 **JKFF**（JK 正反器），存在檔案裡是 `kind: 'BLOCK'`、`chip: 'DFF' | 'JKFF'`。
  - DFF：輸入 D、CLK、/PRE、/CLR，輸出 Q、/Q。行為和 74LS74 的一組一樣（上升緣）。
  - JKFF：輸入 J、CLK、K、/PRE、/CLR，輸出 Q、/Q。行為和 74LS76 的一組一樣（下降緣）。
  - 沒接的輸入和整顆 IC 一樣：/PRE、/CLR 不用（1），D、J、K 是 0，CLK 是 1。
- 模擬直接用那顆 IC 的模型（第 1 組的腳），另一組的腳用沒接時的值。所以行為和整顆 IC 完全一樣，時序表、波形、比對都不用改。

## 3. 轉成麵包板

- 轉換前把單顆正反器兩顆一組合成一片 IC（DFF → 74LS74、JKFF → 74LS76），第一顆用第 1 組的腳、第二顆用第 2 組；單數時最後一片只用第 1 組（第 2 組照沒接處理）。
- 依畫面上的位置（上到下、左到右）配對，相鄰的正反器在同一片 IC。
- 材料表、說明、佈線、送脈衝比對都用合好的 IC，所以和直接放整顆 IC 的結果一樣。

## 4. 範例與 MCP

- 範例「2 位元同步計數器（D 型正反器）」：兩顆 DFF 共用時脈；D0 = /Q0、D1 = Q1 XOR Q0；輸出 Q0、Q1，數 0 1 2 3 0。轉換用一片 74LS74 與一片 74LS86。
- MCP：`logic_set` 的說明列出 `DFF`、`JKFF`（腳名與沒接時的值），伺服器說明的時序電路流程與 `public/mcp/index.html` 跟著改。

## 5. 不做

- 正反器的時脈或輸出畫成不同的符號（三角形、圈圈）：方塊照現在的畫法，腳名寫 CLK、/Q。
- T 型正反器、SR 閂鎖（實驗箱用 74LS74 / 76 接出來即可）。

## 6. 測試與驗收

- 模擬：DFF 的 D 接 /Q 時每個脈衝翻轉；/CLR 接 0 時一直是 0；JKFF 的 J = K = 1 時每個脈衝翻轉。
- 合併：3 顆 DFF 變兩片 74LS74，接線對到正確的腳，合併前後的時序表一樣。
- 轉換：範例轉成 74LS74 × 1、74LS86 × 1。
- 端對端：打開範例，時序表數 0–3，轉成麵包板後「16 個脈衝全部一致」。

# 在自己畫的邏輯圖上顯示布林式（子專案 40）設計規格

- 日期：2026-10-23
- 狀態：實作中（分支 `feat/diagram-formulas`）
- 出處：`docs/ideas/backlog.md`「布林式顯示」；使用者 2026-10-23 選了這一項，說「開始」（不問問題直接做，下面的決定都是我做的，可以改）。

---

## 1. 要做什麼

學生自己畫好邏輯圖之後，可以直接看到每個輸出的布林式，用來寫實驗報告、對答案。每個輸出列兩種式子：

1. **照圖寫出來**：照著閘一層一層寫，不化簡（例如兩個 NAND 接成的圖寫成 `((AB)'C)'`）。這是報告上「寫出電路的布林函數」那一步。
2. **化簡後**：從真值表化簡成最簡的積項和（和題目分頁的化簡一樣），用來對照自己的式子對不對、還能不能更簡單。

## 2. 顯示在哪裡

- **真值表分頁**：表格下面多一區「布林式」，每個輸出一行照圖寫出來的式子、一行化簡後的式子。
  這一區有一個「在圖上顯示」的勾選框。
- **邏輯圖上**：勾選「在圖上顯示」後，每個輸出端下面顯示照圖寫出來的式子（字不跟著元件轉向，永遠是正的）。
  預設不勾（圖比較乾淨）；勾選狀態只在這次使用中記住，不存進檔案，不進 Undo。
- **屬性分頁**：選取一個輸出端時，也列出它的兩種式子。
- **MCP `logic_truth_table`**：真值表後面加上每個輸出的兩種式子，別的 AI 工具也看得到。

## 3. 式子的寫法

- 和「輸入布林式」同一套寫法，複製下來可以直接貼回去：`'` 是反相、連寫是 AND、`+` 是 OR、`⊕` 是 XOR。
  優先順序 反相 > AND > XOR > OR，需要時才加括號。
- NAND 寫成 `(AB)'`，NOR 寫成 `(A + B)'`；單一字母反相寫 `A'`，其他反相整組加括號再加 `'`。
- 輸入名稱不是「一個英文字母加數字」（例如 `Cin`）時，AND 改用 `·` 隔開，免得連寫看不出是哪幾個字母（這種名稱「輸入布林式」讀不了，所以不能貼回去）。
  常數接在 AND 裡也用 `·`（`A·1`，因為 `A1` 會被讀成一個變數）。
- 化簡後的式子用同樣的規則（不用上橫線），兩行可以直接比較。

## 4. 寫不出來的情況

| 情況 | 照圖寫出來 | 化簡後 |
|---|---|---|
| 有閘的輸入沒接 | 沒接的地方寫 `?` | 寫不出來（說明有輸入沒接） |
| 經過 IC 方塊（74LS83 等） | 寫不出來（說明經過 IC 方塊） | 照常（從真值表化簡） |
| 邏輯圖有迴圈 | 都寫不出來（說明有迴圈） | 同左 |
| 輸入超過 8 個 | 照常 | 寫不出來（真值表太長） |
| 輸出端沒接 | 寫 `?` | 寫不出來 |
| 7 段顯示器 | 不列（布林式只列一般的輸出端），區塊下方說明一句 | 同左 |

## 5. 不做

- 不畫上橫線的寫法（和輸入布林式的寫法一致，方便複製）。
- 不把照圖寫出來的式子自動「部分化簡」（例如 `(A')'` 不改成 `A`），照圖寫就是照圖寫。
- 同一個閘接到好幾個地方時直接重複寫，不另外取中間變數名稱。

## 6. 驗收

- 照圖寫出來的式子貼回「輸入布林式」解析後，真值表和邏輯圖一樣（單元測試用好幾種圖檢查）。
- 第 4 節每一種情況都有測試。
- 網頁：真值表分頁看得到兩種式子；勾「在圖上顯示」後輸出端下面出現式子，取消後消失；選取輸出端時屬性分頁也有。
- MCP `logic_truth_table` 回覆裡有布林式。

# 轉成麵包板的擺放改善與低態致動 LED（子專案 36、37）設計規格

- 日期：2026-10-20
- 狀態：實作中（使用者 2026-10-19 看過比較結果說「可以嘗試」）
- 出處：使用者給了三張別的 AI 透過 MCP 做出來的麵包板（A 一位元比較器、B 3 對 8 線解碼器（低態致動）、C 8 對 3 線編碼器），
  說「這三張是理想的要求」，要繼續改善佈線。

---

## 1. 比較的結果（2026-10-19，照圖重建電路後量的）

| 電路 | 圖 | 我們「轉成麵包板」 |
|---|---|---|
| A 一位元比較器（74LS02、下拉電阻） | MB-102，24 條線，總長 87 | 37 條、總長 174 |
| B 3 對 8 解碼器（74LS138、8 顆 LED） | MB-102，29 條線 | MB-102 排不完，改用 EIC-1106 |
| C 8 對 3 編碼器（3 顆 74LS32） | 73 條（就是我們的結果） | 73 條、總長 356 |

- 零件位置相同時，我們的 AI 佈線排出來的線和圖**一模一樣**（A、B 都是）：差別在「轉成麵包板」把零件擺在哪裡。
- 試驗（之後丟掉的程式）量到的：
  - **上 / 下拉電阻直立**，一端插在開關那一排、另一端直接插進電源軌（圖 A 的接法）：A 37 → 25 條、多數決加電阻 41 → 26 條。
  - **零件間隔**：現在固定「平均分開、最多 6 欄」。小電路用 2 欄最好（A 總長 137 → 105），大電路還是 6 欄最好；沒有一個間隔每次都最好。
  - **LED 跨凹槽**（電阻直立跨過中間凹槽、LED 在 I 列，每顆 2 欄，圖 B 的擺法）：B 45 → 41 條、C 73 → 66 條；A 反而變差。
  - **LED 分兩邊**（一半放在開關左邊、一半放在 IC 右邊，圖 B 的擺法）：B（不加電阻）在 MB-102 排得完（34 條）。
  - 只看「零件不動」的佈線來挑擺法會看錯（BCD 不動時排不完、搬 IC 後排得完），所以每個擺法要用「可移動 IC」的佈線快速試一次。

## 2. 目標

**子專案 36：擺放**

1. 上 / 下拉電阻直立：開關接 +5 V 時，下拉電阻從開關那一排的 J 列直接插進下方的 − 軌；開關接 GND 時，上拉電阻從 A 列直接插進上方的 + 軌。
   那一排剛好是電源軌沒有孔的欄（軌每 6 欄少一個孔）時，先把開關往右挪（最多 5 欄）；挪不了的那個輸入照舊用平放的電阻加一條線。按鈕照舊。
2. 擺法的選項（內部用，不是畫面上的選項）：零件間隔 2、3、4、6 欄；LED 的擺法「上下兩組」（現在的）或「跨凹槽」；
   LED 分兩邊（只在 MB-102、4 顆以上）。
3. 轉換時**試好幾種擺法**：每一種用「可移動 IC」的佈線在短時間內試一次，挑最好的（接不完的線少 → 交叉少 → 線少 → 總長短，和現在比較佈線的順序一樣），
   再用剩下的時間把最好的那一種排到最好。自動選板時 MB-102 都排不完才換 EIC-1106。
4. 網頁的「轉換」與 MCP 的 `logic_to_breadboard` 都這樣做；網頁在 Worker 裡算，畫面顯示「轉換中」，算完一樣是兩步 Undo（轉換、佈線）。
5. 修正：初始的 5V / GND 符號固定插在第 3 欄，會和直立的電阻搶同一個孔；改成插在電源軌第一個空的孔。

**子專案 37：低態致動 LED**

1. 邏輯圖的輸出端可以設成「低態致動」（0 時亮）：屬性面板切換，畫面上燈號 0 時亮；檔案存 `activeLow: true`。真值表與比對仍然寫訊號的 0 / 1。
2. 轉成麵包板：低態致動的 LED 正極接 +5 V、負極經過 220 Ω 接到輸出（圖 B 的接法）；「上下兩組」與「跨凹槽」兩種擺法都支援。
3. 依名稱比對（邏輯圖、題目）讀麵包板的 LED 時，**正極接在 +5 V 的 LED 亮 = 0**，其他 LED 亮 = 1。這樣手接的低態致動電路也能正確比對。
4. MCP `logic_set` 的說明寫上 `activeLow`。

**不做**

- 自己接的板子按「AI 佈線」時的擺放（只動「轉成麵包板」）。
- 改佈線器本身（零件位置相同時已經和圖一樣）。

## 3. 驗收（量測，寫成測試）

| 電路 | 現在 | 目標 |
|---|---|---|
| A 比較器（只用 NOR、下拉電阻） | 37 條 | ≤ 27 條（MB-102） |
| 多數決（下拉電阻） | 41 條 | ≤ 28 條（MB-102） |
| B 解碼器（不加電阻） | EIC-1106 | MB-102 排得完 |
| C 編碼器 | 73 條 | ≤ 70 條 |
| BCD 範例 | 58 條 | 不變差（≤ 60 條） |
| B 解碼器（低態致動 LED，子專案 37） | — | 排得完，比對全部一致 |

- 時間：每個驗收電路「轉換 + 佈線」在本機 40 秒內。
- 快的（A、多數決）放進一般的單元測試；慢的放在另外的量測測試（`npm run bench:convert`，不在 CI 跑）。
- 現有的轉換測試照樣要過（照計畫接線、和邏輯圖比對全部一致、電源接最近的軌）。

## 4. Claude 做的決定（看規格時可以改）

- 試的擺法：間隔 2、3、4、6 × LED 兩種擺法 × 分兩邊（MB-102、4 顆以上），重複的不試；試的總時間約 15 秒，剩下的時間給最好的那一種。
- 低態致動是**輸出端的屬性**（不是整次轉換的選項），因為同一張圖可以有高態、低態兩種輸出。
- 讀 LED 的規則看接法（正極接 +5 V 就是低態致動），不看邏輯圖的設定，手接的板子也適用。

# 時序圖（波形）（子專案 50）設計規格

- 日期：2026-10-25
- 狀態：實作中（分支 `feat/waveform`）
- 出處：`docs/ideas/backlog.md`「時序電路的其他功能」，使用者 2026-10-25 選這一項。
  它有四個獨立的功能（波形、多個時脈、單顆正反器、從狀態表產生電路），一次做一個；先做波形。
  使用者沒有做過這些實驗，擺法交給我決定（瀏覽器上的示意圖給使用者看過：選 A）。

---

## 1. 目的

子專案 46 的「時序表」把每次脈衝後的輸出列成表格。上計數器、正反器實驗時，課本和示波器看的都是波形：
每個訊號一條線、高是 1、低是 0，一眼看出 QA 每次翻轉、QB 每兩次翻轉。這次把同一份結果畫成波形。

不做：多個時脈、非時脈的輸入在中途改變、實際的傳遞延遲（波形只畫每次脈衝之後穩定的值）、匯出圖片。

## 2. 畫面

- 「時序表」分頁上方多兩個按鈕「表格」「波形」（預設表格；切換的選擇留在畫面狀態裡，不存檔、不進 Undo）。
  「列到第 8 / 16 / 32 次脈衝」兩邊共用。
- 波形的資料就是 `sequenceTable` 的結果，所以和表格一定一致。
- 由上往下：時脈（名稱用時脈節點的名稱）、每個輸出端、每個顯示器（順序和表格的欄一樣）。左邊寫名稱，底下寫第幾次脈衝（0 到 n）。
  - 第 k 格是第 k 次脈衝結束（時脈回到 0）之後的值；第 0 格是重設、還沒有脈衝。
  - 時脈：第 k 次脈衝畫在第 k − 1 格的後半（升起後在第 k 格開頭落下），所以輸出在格線上改變。
    （74LS90 / 93 / 76 在下降緣動作，剛好對齊；74LS74 / 161 / 193 在上升緣，畫的位置晚半格，說明文字寫「每格是那次脈衝之後的值」。）
  - 輸出端：1 畫高、0 畫低；不確定（X）畫在中間的灰色線，標「?」。
  - 顯示器：一格一格的框，裡面寫表格裡的值（數字、帶小數點、或亮的段）；放不下時縮小字。
- 每格固定寬度，32 次脈衝時比側邊欄寬就可以左右捲動。
- 滑鼠（或手指）移到圖上，出現一條直線標出那一格，底下一行文字寫「第 5 次脈衝後：QA = 1、QB = 0、…、S1 = 5」；
  沒有指著時寫「把滑鼠移到圖上看每次脈衝後的值」。
- 時序表不能算（迴圈、沒有時脈、沒有輸出）時，兩種顯示都用原本的說明。

## 3. MCP

`logic_truth_table` 對時序電路回傳時序表之後，再加一段文字波形（AI 看不到畫面）：每個輸出端一行，每次脈衝一個字元，
1 是 `‾`、0 是 `_`、不確定是 `?`，時脈一行寫成每格 `|`（表示每格前有一個脈衝，第 0 格是 `.`）。顯示器不畫（值在表格裡）。
伺服器說明與 `public/mcp/index.html` 的時序電路說明提到波形。

## 4. 測試

- 單元：文字波形（十進位計數器 10 次脈衝：QA `_‾_‾_‾_‾_‾_`、QD 在第 8、9 格是 1）；有 X 時是 `?`。
- 畫面（store 測試或元件的純函式）：波形的格數、時脈與輸出的路徑由 `sequenceTable` 的列算出（純函式 `waveLanes`）。
- MCP：`logic_truth_table` 的回覆有「波形」一段。
- 端對端：十進位計數器的時序表切到「波形」，看到 QA–QD 與顯示器；滑鼠移到第 5 格，文字寫 QA = 1、QC = 1；切回表格還在。

## 5. 驗收

- 時序表分頁可以切換表格 / 波形，值和表格一樣，列數設定共用。
- 波形有時脈、每個輸出端、顯示器；指著某一格時寫出那一格的值。
- MCP 的時序表多一段文字波形；說明跟著改。

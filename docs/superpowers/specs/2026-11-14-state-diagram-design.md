# 狀態圖（只顯示）（子專案 63）設計規格

- 日期：2026-11-14
- 狀態：完成（PR 合併時一起發布）
- 出處：使用者 2026-11-14 選代辦事項第 2 項「時序電路的其他功能」，分三次做；狀態圖選「只顯示」（從狀態表題目自動畫，不能在圖上改題目）。

## 1. 畫法

- 每個狀態一個圓圈，S0（重設後的狀態）用藍色粗框；圓圈排在一個圓上，S0 在最上面、順時針（2 個狀態時左右各一個）。
- 狀態表每一列一個箭頭（現在狀態 → 下一個狀態）；同一對狀態之間的箭頭合成一條，標籤用逗號隔開。
  兩個狀態互相有箭頭時兩條往不同邊彎；回到自己的箭頭畫在圓圈外側。
- 標籤：
  - Mealy（預設）：箭頭寫「輸入/輸出」，例如 `1/0`。
  - Moore：每個狀態的輸出都和輸入無關時，輸出寫在圓圈裡（`S0/1`），箭頭只寫輸入。
  - 沒有輸出時箭頭只寫輸入；沒有輸入時（計數器）箭頭不寫字。
- 下一個狀態是 X（不在乎）的列不畫箭頭，圖下面寫有幾列。
- 外框跟著圓圈的範圍，四周留空間給回到自己的箭頭與標籤；直的箭頭標籤放在靠起點的地方，經過圖中間的直線很多時才不會疊在一起。

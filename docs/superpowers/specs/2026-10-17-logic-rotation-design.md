## 0. 目的

邏輯圖現在一律「輸入在左、輸出在右」。畫回授（輸出接回前面的閘）、上下排列的電路時，元件轉不了方向，線只能繞來繞去。
這個子專案讓邏輯閘與 IC 方塊可以轉 90°、180°、270°，線跟著從正確的方向接進每一隻腳。

## 1. 決定

| 項目 | 決定 |
|---|---|
| 哪些元件可以轉 | 邏輯閘（AND、OR、NOT、NAND、NOR、XOR）與 IC 方塊；輸入端、輸出端、5V / GND、7 段顯示器不轉（有文字或數字的方向，也是課本「輸入在左、輸出在右」的慣例）。子專案 28 起輸入端、輸出端、常數也能轉，只有顯示器不轉 |
| 角度 | 順時針 0、90、180、270 度；存成 `rotation`（0 不寫） |
| 怎麼轉 | 選取後按 R（和麵包板一樣）轉 90°；屬性面板「方向」四個按鈕（輸出朝右、下、左、上）。可以一次轉好幾個選取的元件；每個元件繞自己的中心轉 |
| 轉了會重疊 | 不轉，說明「轉向後會和別的元件重疊」 |
| 線 | 連到哪一隻腳不變；每個來源的匯流線在輸出的那一側（朝右：右邊的直線；朝下：下面的橫線…），線從輸入腳朝外的那一側接進去；穿過元件或和別的訊號疊在一起時照現在的方法繞開 |
| IC 方塊的字 | 腳名、型號一律正著寫（不跟著轉）；腳的位置跟著轉 |
| 不做 | 鏡射（左右翻轉但不旋轉）、放置時先轉好（放好再按 R）、輸入端 / 輸出端 / 常數 / 顯示器轉向 |

## 2. 幾何（`src/logic/shapes.ts`）

- `LogicNode.rotation?: 90 | 180 | 270`。
- 本地座標：沒轉時的腳位（輸入在 u = 0、輸出在 u = w；v 是列）。轉向把本地座標 (u, v) 換到：
  90°：(h − 1 − v, u)；180°：(w − u, h − 1 − v)；270°：(v, w − u)。
- `inputPins` / `outputPins` 套用轉向；`boxOf(node)`：佔用的方框（90° / 270° 時寬高互換），重疊、框選、Fit、對齊都用它；
  `nodeSize` 仍是沒轉時的大小（畫元件用）。
- `bodyRect(node)`：本體在畫面上的範圍（開區間，線穿過它就算穿過元件）；沒轉時是 (x, x + w) × (y − 0.5, y + h − 0.5)，轉向時把四個角換過去。
- `outputDir(node)` / `inputDir(node)`：輸出朝的方向、輸入腳朝外的方向（右、下、左、上）。

## 3. 線（`src/logic/wiring.ts`）

- 匯流線：同一個方向、同一條線上的輸出腳排在一起，依沿線的位置各挪一格（和現在同一欄的來源一樣）。
- 每條線先轉到「來源朝右」的座標裡產生候選路線，再轉回來檢查：
  - 目的腳朝左（沒轉的閘）：和現在一樣（直接走；擋到就上下找空列、繞到腳的左邊）。
  - 目的腳朝右：一樣，但繞到腳的右邊。
  - 目的腳朝上 / 朝下：沿匯流線走到腳的上面（下面）一列，橫走到腳的正上方（正下方），再直直接進去；擋到就再往外找空列。
- 檢查（穿過元件、沿著別的訊號的線或輸出短線）、分岔黑點都和現在一樣；分岔黑點在各來源自己的座標裡算。
- 沒轉的圖畫出來和現在完全一樣。

## 4. 畫面

- 閘：整個符號跟著轉（SVG 轉向）。IC 方塊：依轉向畫方框與腳，字正著寫。
- 屬性面板（選了閘或 IC 方塊）：「方向」四個按鈕，旁邊寫「選取後按 R 轉 90°」。
- 快捷鍵 R：邏輯圖畫面、有選取時轉向；選取裡沒有能轉的元件時提示「只有邏輯閘和 IC 方塊可以轉向」。

## 5. 讀檔、其他

- `parseLogicDiagram`：`rotation` 只能是 90、180、270，而且只有閘與 IC 方塊可以有；不合法就說明原因。
- 複製貼上、移動、Undo 都保留轉向；模擬、真值表、轉成麵包板不受影響（只看連接）。

## 6. 測試

- 單元：四個角度的腳位、方框與本體範圍；轉向保持中心、重疊時不轉、不能轉的元件；讀檔來回與錯誤；
  線：從朝左 / 朝下 / 朝上的輸出接出、接進朝右 / 朝上 / 朝下的輸入（固定的例子與期望路線）；隨機轉向的圖每條線都從輸出腳出發、
  從正確的一側接進輸入腳、只有水平與垂直線段；沒轉的範例畫法不變（現有的測試）。
- 端對端：放一個 AND、按 R 兩次（轉 180°）→ 腳換到另一邊；接線後真值表不變；屬性面板的方向按鈕；Undo。

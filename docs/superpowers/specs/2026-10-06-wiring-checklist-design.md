# 接線清單（照著插實體麵包板）設計規格

- 日期：2026-10-06
- 狀態：已完成（2026-10-06）
- 來源：`feat/core-engine` 分支的編輯器設計第 9 節（另一套子專案 2 實作），移植到主線的架構
- 需求文件第三十四章：學生先在網頁上規劃，再照著插實體麵包板

---

## 0. 目的

學生按完「AI 標準佈線」後，要照著畫面一條一條把跳線插到實體麵包板上。接線清單把所有導線依「先電源、再接地、最後訊號」
列出來，每條寫清楚顏色、從哪個孔到哪個孔、多長；插好一條就打勾，畫面上那條線變淡，剩下沒插的線一目了然。

## 1. 決定

| 項目 | 決定 |
|---|---|
| 列出哪些導線 | 目前電路的**所有**導線（AI 標準佈線或手動接線都可以照著插） |
| 順序 | Net 種類（電源 → 接地 → 訊號 → 沒有接到元件腳的線），同類依 Net 名稱、導線 ID 的自然順序（`NET_2` 在 `NET_10` 前面） |
| 每一列 | 勾選框、色塊與中文色名、`起點 → 終點`（多塊板時含板子 ID）、長度（格）、Net 名稱 |
| 勾選狀態 | `wireId → 勾選當時的樣子`（兩端孔位、長度、顏色）。導線被重新佈線或改色後自動變回未完成，不需要另外判斷「清單過期」；Undo 回到同一條線時勾選又會出現 |
| Undo | 打勾不是編輯，不進 Undo、不算未儲存的修改 |
| 存檔 | 自動儲存與「儲存」的專案會一起保存勾選狀態（`CircuitFile.checklist`，選填欄位，舊檔案照樣能開）；匯出 JSON 不含勾選狀態 |
| 畫面 | 右側面板新增「接線清單」分頁：已完成 / 總數與進度條、全部清除，依電源 / 接地 / 訊號分段；點一列 = 選取那條線（只標出這一條，不高亮整個 Net）、其他導線變淡、畫面移到那條線 |
| 板上顯示 | 已打勾的導線畫成半透明 |

## 2. 程式

- `src/editor/checklist.ts`（不依賴 DOM）：`checklistRows`、`wireKey`、`isChecked`、`setChecked`、`pruneChecklist`、
  `checklistProgress`、`colorName`、`naturalCompare`。
- `fileFormat`：`toCircuitFile(..., checklist)`、`parseCircuitData` 讀回 `checklist`（只保留字串對字串的項目）。
- store：`checklist` 狀態、`setWireChecked`、`clearChecklist`；`select(selection, { keepTab })` 讓清單點選時不切換分頁。

## 3. 測試

- 單元測試：排序（種類、自然順序）、色名、勾選後重新佈線自動失效、清理、存檔格式往返。
- store 測試：打勾、全部清除、載入其他電路時重設。
- 端對端：載入範例 → AI 標準佈線 → 打開接線清單 → 打勾 → 重新整理後勾選仍在 → 全部清除。

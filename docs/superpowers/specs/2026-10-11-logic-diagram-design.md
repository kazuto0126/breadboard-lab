# 邏輯圖編輯器（子專案 12）設計規格

- 日期：2026-10-11
- 狀態：已完成（2026-10-12）
- 來源：使用者 2026-10-11 的需求「使用者可在前端透過拖拉生成邏輯電路圖（AND、OR、NOT 等邏輯閘、輸入端與輸出端），
  系統自動解析電路拓撲，轉換為實體麵包板電路佈線圖（74LS IC、指撥開關輸入、LED 輸出）」。拆成兩個子專案：
  - **子專案 12（這份）**：邏輯圖編輯器、模擬、真值表、存檔。
  - 子專案 13：邏輯圖轉成麵包板（選 IC、分配閘、產生開關與 LED、交給 AI 佈線、用真值表比對模擬結果）。

---

## 0. 目的

學生先在網頁上畫出課本上的邏輯圖（例如「圖 2-5」X = AB + AC + BC），用真值表與模擬確認邏輯正確；
子專案 13 再把同一張圖轉成麵包板。所以這次的資料要能讓下一步準確讀出「有哪些閘、怎麼連」。

## 1. 決定（使用者確認）

| 項目 | 決定 |
|---|---|
| 位置 | 同一頁切換「邏輯圖｜麵包板」；元件庫、右側面板、存檔共用（使用者選擇） |
| 邏輯閘 | AND、OR、NOT、NAND、NOR、XOR；AND / OR / NAND / NOR 可以設 2、3、4 個輸入，XOR 固定 2 個、NOT 1 個（使用者選擇） |
| 和麵包板的關係 | 單向：子專案 13 按「轉成麵包板」才產生麵包板；改麵包板不會改邏輯圖（使用者選擇） |
| 邏輯圖本身的功能 | 自動算真值表、在邏輯圖上模擬（使用者選擇）。不做布林式顯示、不做從布林式畫圖 |
| 時序元件 | 不做（正反器之後再說）；有迴圈就是錯誤 |
| 旋轉 | 不做：輸入一律在左、輸出在右 |
| Undo | 邏輯圖有自己的 Undo 紀錄；Ctrl+Z / Ctrl+Y 與工具列的復原、重做作用在目前看的那一邊 |

## 2. 資料

```ts
type GateKind = 'AND' | 'OR' | 'NOT' | 'NAND' | 'NOR' | 'XOR';

interface LogicNode {
  id: string;            // g1、g2…（閘）、i1…（輸入端）、o1…（輸出端）
  kind: GateKind | 'INPUT' | 'OUTPUT';
  x: number;             // 格子座標（整數）：元件左上角
  y: number;
  inputs?: number;       // 只有閘：AND / OR / NAND / NOR 為 2–4；NOT = 1；XOR = 2
  name?: string;         // 只有輸入端、輸出端：A、B、C…／X、Y、Z…
  value?: 0 | 1;         // 只有輸入端：開關目前的狀態（會存檔）
}

interface LogicWire {
  id: string;            // w1、w2…
  from: string;          // 來源：閘或輸入端的 id（它們只有一個輸出）
  to: { node: string; pin: number }; // 目的：閘的第 pin 個輸入（從 0 起算），或輸出端（pin = 0）
}

interface LogicDiagram {
  version: 1;
  nodes: LogicNode[];
  wires: LogicWire[];
}
```

- 一個輸出可以接很多條線；每個輸入（閘的一個輸入腳、輸出端）最多一條線：接第二條時取代舊的。
- 不能接：輸出接輸出、輸入接輸入、自己的輸出接自己的輸入（直接迴圈）。間接迴圈可以畫出來，但檢查會報錯（第 4 節）。
- 輸入端、輸出端的名稱不能空白、不能重複（大小寫視為不同）；只能用英文字母、數字、底線，最多 8 個字，第一個字是字母。
  新放的輸入端用第一個還沒用過的 A–Z，輸出端用 X、Y、Z、W、V…（還沒用過的）。

### 2.1 形狀與腳的位置（格子座標）

| 元件 | 大小（寬 × 高） | 輸入腳（相對左上角） | 輸出腳 |
|---|---|---|---|
| 2 輸入閘（含 XOR） | 4 × 3 | (0, 0)、(0, 2) | (4, 1) |
| 3 輸入閘 | 4 × 3 | (0, 0)、(0, 1)、(0, 2) | (4, 1) |
| 4 輸入閘 | 4 × 5 | (0, 0)、(0, 1)、(0, 3)、(0, 4) | (4, 2) |
| NOT | 3 × 1 | (0, 0) | (3, 0) |
| 輸入端 | 2 × 1 | — | (2, 0) |
| 輸出端 | 2 × 1 | (0, 0) | — |

- 閘的圖示用 IEEE 標準形狀（D 形 AND、盾形 OR、XOR 多一條弧線、NAND / NOR / NOT 輸出端小圓圈）。
- 輸入端：左邊是名稱與開關圖示（0 / 1），右邊是輸出腳。輸出端：左邊是輸入腳，右邊是名稱與燈號（0 / 1 / ?）。
- 元件之間可以相鄰但不能重疊（以大小的方框判斷）；放不下時預覽變紅、放開不會放。

### 2.2 線的畫法

同一個來源的所有線共用一條直的「匯流線」，位置在來源輸出腳右邊 1 格：
從輸出腳往右到匯流線，沿匯流線上下走到目的那一列，再水平走到目的輸入腳（目的在來源左邊時一樣照這個走法，可能會穿過元件，畫面上照畫）。
匯流線上有兩條以上的線分出去時，在分岔處畫實心圓點（像圖 2-5）。這是畫法，不影響資料。

## 3. 計算（`src/logic/`，純函式，不碰網頁）

- 值有三種：0、1、`X`（不確定：沒接好）。
  - AND：有 0 → 0；全部 1 → 1；其他 X。OR：有 1 → 1；全部 0 → 0；其他 X。NOT：0↔1，X → X。XOR：有 X → X，否則奇數個 1 → 1。
  - NAND / NOR 是 AND / OR 再反相。
  - 沒接線的輸入腳是 X；輸出端沒接是 X。
- `evaluate(diagram, values)`：依拓撲順序算出每個閘與輸出端的值；`values` 是每個輸入端的 0 / 1。有迴圈時回傳迴圈錯誤、不計算。
- `truthTable(diagram)`：輸入端依名稱排序（字母順序，第一個是最高位元），從全 0 數到全 1；輸出端也依名稱排序。
  超過 8 個輸入端時不產生（回傳「輸入太多」）。

## 4. 檢查

| 代碼 | 嚴重度 | 條件 | 訊息範例 |
|---|---|---|---|
| `LOGIC_LOOP` | 錯誤 | 線形成迴圈 | g2、g3 形成迴圈：邏輯圖只能畫組合邏輯（輸出不能再接回前面） |
| `LOGIC_INPUT_OPEN` | 警告 | 閘的輸入腳沒接 | g1（AND）第 2 個輸入沒有接線，值不確定 |
| `LOGIC_OUTPUT_OPEN` | 警告 | 輸出端沒接 | 輸出 X 沒有接到任何閘 |
| `LOGIC_UNUSED` | 警告 | 閘或輸入端的輸出沒有接到任何地方 | g4（OR）的輸出沒有接到任何地方 |
| `LOGIC_NO_IO` | 警告 | 沒有輸入端或沒有輸出端（有任何閘時才檢查） | 邏輯圖還沒有輸入端 / 輸出端 |

右側面板的「檢查」分頁在邏輯圖這邊列出這些項目；點一項會選取並移到那個元件。

## 5. 畫面

- **切換**：工具列左邊（「檔案…說明」選單後面）加「邏輯圖｜麵包板」切換（`data-testid="view-switch"`）。
  麵包板那邊不變；切到邏輯圖時，MANUAL / AUTO ROUTE / COMPARE、AI 佈線、模擬、Check Circuit 這些麵包板按鈕隱藏。
- **元件庫**：邏輯圖時換成「邏輯閘」清單：AND、OR、NOT、NAND、NOR、XOR、輸入端、輸出端（每個有小圖示）。
  拖到畫布放下，或點一下再點畫布（平板）。放下時對齊格子。
- **畫布**（`data-testid="logic-canvas"`）：淺色格點背景；滾輪縮放、拖曳空白處平移（和麵包板一樣的操作）；「Fit」顯示全部。
- **連線**：從一個腳按下拖到另一個腳放開（預覽線跟著游標）；起點可以是輸出腳或輸入腳。不合法時預覽變紅、放開不會建立。
- **選取與編輯**：點元件或線選取；拖曳元件移動（線跟著）；Del 刪除選取的元件（連同它的線）或線；Esc 取消放置或連線。
- **輸入端的開關**：點開關圖示切換 0 / 1（點名稱或其他地方是選取）。開關切換不進 Undo，但會存檔。
- **顏色**：值是 1 的線與腳用紅色、0 用藍色、X 用灰色；輸出端燈號同色並顯示 1 / 0 / ?。
- **右側面板**（邏輯圖時三個分頁）：
  - 屬性：選到閘時可以改種類（六種）與輸入數（2–4，改少時拿掉多出來的那幾條線）；選到輸入端、輸出端時可以改名稱（不合法時顯示原因、不改）；什麼都沒選時顯示元件與線的數量。
  - 真值表（`data-testid="truth-table"`）：表頭是輸入與輸出名稱；目前開關組合的那一列標亮；點一列把開關設成那個組合；
    有迴圈時顯示迴圈錯誤；超過 8 個輸入時顯示「輸入超過 8 個，真值表太長（256 列以上），請用模擬檢查」。
  - 檢查：第 4 節。
- **狀態列**：邏輯圖時顯示「閘 N・輸入 N・輸出 N・線 N」。

## 6. 存檔、自動暫存、範例

- 檔案格式不升版：`CircuitFile` 多一個可省略的 `logic?: LogicDiagram`；舊檔沒有這個欄位就是空的邏輯圖。讀檔時檢查格式（種類、輸入數、線的兩端存在且方向正確、名稱規則），不合法時整個檔案拒絕並說明哪裡錯。
- 存檔、另存、匯出 JSON、自動暫存（localStorage）、「未儲存」判斷都把邏輯圖算進去；開新電路時邏輯圖也清空。
- 範例選單加「多數決電路（圖 2-5）」：A、B、C 三個輸入端，三個 AND（AB、AC、BC），一個 3 輸入 OR，輸出 X。載入時切到邏輯圖、麵包板是空的。

## 8. 測試

- **單元測試**（`tests/logic/`）：
  - 三值計算的每一種閘（含 X）；2 / 3 / 4 輸入；NAND / NOR / XOR。
  - 圖 2-5 的真值表 8 列：X = 1 的列是 011、101、110、111。
  - 迴圈偵測；每一種檢查項目；超過 8 個輸入不產生真值表。
  - 編輯：輸入腳接第二條線會取代、輸出接輸出不行、自己接自己不行、改輸入數拿掉多的線、刪元件連線一起刪、重疊不能放、名稱規則與重複。
  - 讀檔：合法、舊檔沒有 logic、各種不合法的錯誤訊息；存檔再讀回相同。
- **store 測試**（`tests/web/`）：邏輯圖的 Undo / Redo 與麵包板分開；開關不進 Undo；開新電路清空；自動暫存帶上邏輯圖；未儲存判斷。
- **端對端**（`e2e/logic-diagram.spec.ts`）：切到邏輯圖 → 用滑鼠放 A、B、C、三個 AND、一個 OR（改成 3 輸入）、輸出 X → 拖出 9 條線
  → 真值表 8 列正確 → 點開關 A、B 為 1，X 的燈變 1 → 點真值表 000 那列，X 變 0 → 存檔再開，圖還在。

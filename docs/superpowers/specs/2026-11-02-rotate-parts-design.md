# 麵包板上的元件旋轉（子專案 56）設計規格

- 日期：2026-11-02
- 狀態：已實作（分支 `feat/rotate-parts`）
- 出處：使用者 2026-11-02 要求「檢查一般和 MCP 接口部分麵包板是否能正常旋轉，若不行需修正」。
  需求文件（38.1、38.17）規定麵包板本身不旋轉（多塊板一定同方向），所以檢查的是板上元件的旋轉（R、右鍵「旋轉 90°」）。

---

## 1. 檢查結果

用元件庫全部 57 種元件，在 MB-102 與 EIC-1106 上試放 0 / 90 / 180 / 270 度，並用網頁的旋轉連轉 4 次：

| 項目 | 結果 |
|---|---|
| IC、指撥開關（DIP） | 只能 0 / 180（要跨過凹槽），按 R 直接翻 180°，轉回來在原位 —— 正常 |
| 電阻、VCC / GND、時脈、7 段顯示器 | 轉 4 次回到原位 —— 正常 |
| LED、電容、DC 電源、按鈕 | **轉 4 次位置跑掉**（中心在兩個孔中間，每次四捨五入往同一邊偏一格；靠近凹槽時放不下的方向被挪到附近，之後也偏） |
| MCP | **不能轉已經放好的元件**（只有 `place_part` 放的時候能指定角度）；IC 指定 90 / 270 度只回「腳不在孔上」，看不出原因 |

## 2. 修正

- 旋轉的軸：以中心轉完剛好在孔上就照中心轉（電阻、IC）；中心在兩個孔中間、又不是 DIP 的元件（LED、電容、按鈕…）一律以第 1 腳為軸。
- 先找轉完不用挪就放得下的方向，放不下的方向跳過（例如 F 列的 LED 往上會跨過凹槽），都不行才挪到附近。
  所以轉回原本的方向時一定在原本的位置。
- MCP `set_part` 新參數 `rotation`（0 / 90 / 180 / 270），規則和網頁一樣，回覆轉完每隻腳在哪個孔；
  IC（DIP）指定 90 / 270 時說明「IC 要跨過中間的凹槽，只能轉 0° 或 180°」（`place_part` 也是）。
- 工具說明與設定說明頁跟著改。

## 3. 測試

- 單元：全部元件在兩種麵包板上一直轉，轉回原本的方向時位置一樣。
- MCP：LED 轉 90° 再轉回 0° 回到原位；45° 拒絕；IC 90° / 270° 說明原因、180° 可以。
- 端對端：LED 按 R 四次是 90 / 180 / 270 / 0 且回到原位，右鍵「旋轉 90°」也一樣；原本 IC 按 R 翻 180° 的測試不變。

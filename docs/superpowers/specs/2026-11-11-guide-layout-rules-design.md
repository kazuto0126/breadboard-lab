# 照「麵包板接線 AI 工作指南」最佳化轉換的擺法規則（子專案 60）設計規格

- 日期：2026-11-11
- 狀態：完成（PR #96，已發布）
- 出處：使用者 2026-11-10 給了「給同學的 AI 接線指南」（整理自圖 8-8、圖 7-8 兩次實作），2026-11-11 要求
  「依照這份 md 最佳化規則」，範圍選「轉換與佈線的規則（程式本身）」。
  起因：圖 10-14～10-17 四題合成一張邏輯圖轉到一塊 EIC-1106，給到 300 秒還差 2 條線。

## 1. 診斷（指南 3.4：卡住時先診斷，不要加算力）

四題互相沒有訊號相連，但轉換把 12 個輸入照名稱排在一個 8 位元加一個 4 位元開關上，每條輸入都要從開關拉到很遠的 IC，
線全部擠在開關附近。多給時間（40 → 240 → 300 秒）結果一樣差 2 條：是擺法的結構問題，不是佈線器的時間不夠。

## 2. 這次做進程式的規則

| 指南 | 規則 | 做法 |
|---|---|---|
| 3.2 先拆成獨立的子結構 | **互相沒有訊號相連的子電路各自成一組** | 擺法多一個選項 `parts`：每個子電路自己的開關、IC、LED 排在一起，一組接一組 |
| 3.7 LED 腳直接插長排 | **LED 直立、一腳直接插進電源軌** | LED 的擺法多一種 `rail`：省一條線、每顆只佔 1 欄 |
| 3.6 面積怎麼算 | **量測佔用面積** | 量測（`npm run bench:convert`）多印「佔用幾欄 × 幾列」，之後每次改擺法都看得到面積 |

### 2.1 子電路分組（`parts`）

- 子電路：用訊號連在一起的輸入端、IC、輸出端。共用的時脈、5V、GND 不算相連；閘放在同一顆 IC 裡算相連（IC 不拆）。
- 順序：依每一組第一個輸入的名稱；沒有輸入的排在後面。沒有接到任何 IC 或輸出端的輸入算在第 1 組。
- 每一組裡的順序：時脈（放在第一個用到它的那一組前面）、開關、平放的輸入電阻、IC、LED。
- 開關：每一組自己的開關，組內照名稱順序；4 個以內用 4 位元、最多 8 個用 8 位元、更多再接一個。零件清單逐個列出。
- 板子：MB-102 排成一排；EIC-1106 從第 1 區開始，一區排不下（區塊之間留不到 2 欄）就排到下一區，
  上 / 下拉電阻與 LED 插進那一區自己的電源軌。
- 只有一個子電路、有 7 段顯示器、或兩塊板的擺法時沒有作用（照原本的擺法）。
- 「轉成麵包板」照舊試好幾種擺法挑佈線最好的；分組是其中幾種，不是強制。

### 2.2 LED 直插電源軌（`rail`）

- 電阻直立跨過凹槽（E → F），LED 也直立：一腳在 J 列（和電阻的下端同一排），另一腳直接插進下方的電源軌。
  一般的 LED 陰極插 − 軌；低態致動的 LED 陽極插 + 軌。腳張開 2 或 3 孔（看那條軌離 J 列多遠）。
- 電源軌每 6 欄少一個孔：5 顆以內挪到連續有孔的欄，更多時跳過沒有孔的欄。
- LED 的腳張開時，兩腳中間的孔不能再插東西、線也不能從下面穿過（元件定義 `blocksBetween` 改成 true；腳距 1 孔時沒有差別）。

### 2.3 閂鎖上電的值不比（指南 5.1 第 7 項：功能模擬要全部正確，但只比確定的格子）

- 四題合成的圖有時脈，比對走時序表：從重設開始送脈衝，每一步都比。閘控 SR 閂鎖、T 電路剛上電、還沒被設定時，
  實體電路是 0 還是 1 不一定（麵包板模擬也算不出確定的值），以前會被當成不一致。
- 改成：有迴授時，邏輯圖用上電是 0 與上電是 1 各算一次時序表，兩次不一樣的格子不比（和真值表的「保持」不比一樣）。

## 5. 測試

- 單元：子電路的判斷（共用時脈不算相連、同一顆 IC 算相連、順序）；分組擺法每一組的開關與名稱；
  `rail` 擺法 LED 一腳在電源軌、沒有接 LED 的線；四題合成的邏輯圖在一塊 EIC-1106 上佈線成功、通過檢查；
  上電是 0 或 1 只影響閂鎖保持的輸出（LS_、T_），正反器（D_、JK_）不受影響。
- 量測：`npm run bench:convert` 前後比較線數與面積，不能變差。

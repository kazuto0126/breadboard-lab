# 拿麵包板直接和狀態表題目比對（子專案 62）設計規格

- 日期：2026-11-14
- 狀態：實作中
- 出處：使用者 2026-11-14 選代辦事項第 2 項「時序電路的其他功能」，分三次做，先做「拿麵包板直接和狀態表比對」
  （之後是狀態圖〔只顯示〕、多個時脈〔各自獨立、一次送一個〕）。

## 1. 目的

學生做時序電路的設計題時，最後是把接好的麵包板拿來對狀態表。子專案 53 只能拿邏輯圖對狀態表；這次讓麵包板（自己手接的
或轉換來的）也能直接對狀態表，網頁的「檢查」分頁與 MCP 都有。

## 2. 對應（依名稱，和子專案 22、24 一樣）

- 題目的輸入：名稱一樣的指撥開關的某一個開關或按鈕（接 +5 V 時 ON = 1、接 GND 時 ON = 0）。
- 題目的輸出與狀態位元 Q0、Q1…：名稱一樣的 LED（低態致動的 LED 照子專案 37 反過來讀）。
- 時脈：麵包板上唯一的時脈元件（沒有或好幾個時說明）。
- 什麼名稱都對不到時顯示提示（怎麼設名稱）；有一部分對不到時列出缺什麼。

## 3. 比對（和子專案 53 同一套走法）

- 重設：麵包板模擬的上電狀態（正反器都是 0），時脈 0、輸入 0；讀 Q 的 LED 得到狀態（應該是 S0）。
- 從走到的每個狀態、每種輸入組合：先讀輸出（脈衝前），再送一個脈衝（0 → 1 → 0）讀下一個狀態；和題目那一列比，X 的格子不比。
  換輸入時 IC 的內部狀態沿用（`adoptSimState`），和實際撥開關一樣。
- 結果和子專案 53 一樣：比了幾列、不一致的列、走不到的狀態、走到沒用到的編碼、重設後不在 S0。
- 走法抽成共用的 `walkStateTask(task, machine)`，邏輯圖與麵包板各自提供「重設」「讀值」「送脈衝」。

## 4. 網頁

- 「檢查」分頁在檔案有狀態表題目時多一張卡「和狀態表比對」：全部一致是綠色，不一致時列出
  「S1、X = 1：題目 → S2、Z = 0；麵包板 → S0、Z = 1」，最後一行寫對應。

## 5. MCP

- `state_task_check` 同時列出「邏輯圖」與「麵包板」兩段（和 `task_check` 一樣）；說明與設定說明頁同步。

## 6. 測試

- 單元：用 state_task_to_diagram 產生的電路轉成麵包板後和狀態表一致；改一條線（或改題目一格）後列出不一致；
  沒有名稱時是提示、少 Q 的 LED 時列出缺什麼；MCP state_task_check 兩段都有。
- e2e：狀態表題目 → 產生電路 → 轉成麵包板 →「檢查」分頁看到「和狀態表比對」全部一致。

# 轉成麵包板更簡潔、開關不接電阻也能用（子專案 19）設計規格

- 日期：2026-10-13
- 狀態：實作中（使用者 2026-10-13 在對話中同意設計）

---

## 0. 目的

使用者 2026-10-13 的需求第 1、3、4 項：轉換出來的麵包板線越少越好；指撥開關沒有上 / 下拉電阻也能正常模擬，只提出警告。

## 1. 理想開關（模擬，`src/core/simulation/simulate.ts`）

- 電位照舊算完（電源、IC 輸出、經電阻傳遞）之後，對每個**斷開**的指撥開關：一端是確定的 0 / 1、另一端沒有任何電位（浮接）時，
  浮接那一端當成相反的電位（弱電位，和經電阻傳來的一樣），然後再經電阻往外傳一次。
  - 開關另一端接 +5 V：ON = 1、OFF = 0。另一端接 GND：ON = 0、OFF = 1。
- 已經有上 / 下拉電阻時，浮接端已經有電位，這條規則不起作用（行為和以前一樣）。
- 只用在指撥開關；按鈕維持原樣。

## 2. 檢查（`src/core/circuit/validate.ts`）

- 新警告 `SWITCH_NO_PULL`：指撥開關第 k 個開關一端接到電源（+5 V 或 GND），另一端的 Net 有 IC 輸入、但沒有任何電阻：
  - 接 +5 V：「⚠ SW1 第 k 個開關沒有下拉電阻：模擬時 OFF 當成 0；實際接線時 OFF 會懸空，TTL 會讀成 1」
  - 接 GND：「⚠ SW1 第 k 個開關沒有上拉電阻：模擬時 OFF 當成 1；實際接線時懸空容易受雜訊影響」
- `INPUT_FLOATING`：IC 一整組閘（`logic.gates` 的一組）的輸入腳和輸出腳都沒有接到任何東西時，視為沒用到的閘，不警告。
  只接了一部分的閘照樣警告。

## 3. 轉換（`src/logic/toBreadboard.ts`）

- 沒用到的閘：輸入腳不再接 GND，完全不接線。
- `ConvertOptions.pulls?: boolean`（預設 false）：false 時不放輸入的上 / 下拉電阻，開關直接接 IC 輸入；true 時和以前一樣。
- 轉換對話框多一個勾選框「加上 / 下拉電阻（實際接線建議勾）」，預設不勾。零件清單跟著變。
- 轉換後的比對照常（用第 1 節的理想開關）。

## 4. 測試

- 模擬：開關接 +5 V、沒有電阻，OFF 讀 0、ON 讀 1；接 GND 時 OFF 讀 1、ON 讀 0；有下拉電阻時結果和以前一樣。
- 檢查：沒有電阻時出現 `SWITCH_NO_PULL`（兩種訊息）；有電阻時沒有；整組沒用到的閘沒有 `INPUT_FLOATING`，接了一半的照樣有。
- 轉換：預設沒有輸入電阻、沒用到的閘腳沒有接線；`pulls: true` 時有電阻；兩種都和真值表一致（含 NAND、7 段顯示器）。
- 端對端：轉換對話框的勾選框改變零件清單；預設轉換後比對全部一致。

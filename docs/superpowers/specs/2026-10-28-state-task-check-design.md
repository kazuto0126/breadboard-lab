# 自己畫的電路和狀態表比對（子專案 53）設計規格

- 日期：2026-10-28
- 狀態：已實作（分支 `feat/state-task-check`）
- 出處：`docs/ideas/backlog.md`「時序電路的其他功能」，使用者 2026-10-28 選第 2 項，照我的建議先做「和自己畫的電路比對狀態表」。

---

## 1. 目的

子專案 52 能從狀態表產生電路，但學生自己畫的電路只能自己看時序表檢查。這次讓狀態表題目像真值表題目一樣，
學生畫完就列出哪幾列不對（哪個狀態、哪種輸入，下一個狀態或輸出錯了）。

## 2. 怎麼對應

- 和真值表題目一樣**依名稱**對應：題目的輸入要有同名的輸入端、題目的輸出要有同名的輸出端；
  **狀態位元**要有輸出端 Q0、Q1…（接到正反器的 Q，Q0 是最低位元），這樣才知道電路現在在哪個狀態。產生的電路本來就有。
- 要有時脈。邏輯圖多出來的輸入端也算對不上（它的值會影響結果）。

## 3. 怎麼比

自己畫的電路不能直接設成某個狀態，所以從重設開始走：

1. 重設後（正反器都是 0）讀 Q，應該是 S0；不是就列出來。
2. 對每個走到的狀態、每種輸入組合：先讀輸出（脈衝前，Mealy 的輸出看現在的輸入），再送一個脈衝讀下一個狀態，和題目那一列比
   （X 的格子不比）。走到新的狀態就從那裡繼續（用走到時的模擬狀態）。
3. 題目裡從 S0 走不到的狀態（電路也沒走到）列為「沒有比對」；走到沒用到的編碼（例如 3 個狀態時的 11）時不再往下走，說明一次。
4. Q 是不確定（X）時算不一致（下一個狀態寫「?」）。

## 4. 畫面與 MCP

- 狀態表題目下面加「和邏輯圖比對」：還不能比對時列原因；一致時寫「比對了 N 列（S0–S3 × 輸入），全部一致」；
  不一致時列出每一列「S1、X = 1：題目 → S2、Z = 0，邏輯圖 → S0、Z = 1」（最多 8 列）。
- MCP 新工具 `state_task_check`（回覆一樣的內容，共 24 個工具）；伺服器說明的狀態表流程與設定說明頁跟著改。
- 不做：拿麵包板和狀態表比對（麵包板先用 `check_against_diagram` / 檢查分頁和邏輯圖比，邏輯圖再和狀態表比）。

## 5. 測試

- 產生的電路（計數器、Mealy 偵測器，D 與 JK）全部一致。
- 接錯的計數器（D0 接 Q0）：S0 的下一個狀態錯，S1–S3 沒有比對。
- 輸出接錯（Z 接成 X）：列出輸出不一致的列。
- 缺 Q 輸出端、缺時脈、缺題目的輸入：列出原因；X 的格子不比。
- MCP 工具；端對端：產生電路後比對全部一致，改一條線後出現不一致。

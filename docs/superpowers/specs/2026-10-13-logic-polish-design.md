# 邏輯圖的小改善（子專案 15）設計規格

- 日期：2026-10-13
- 狀態：已完成（2026-10-13）
- 前一份：`2026-10-11-logic-diagram-design.md`（子專案 12）

## 1. 記住畫面

- 重新整理後回到上次看的那一邊（邏輯圖或麵包板）。
- 只存在這台電腦的瀏覽器（`localStorage` 的 `breadboard-lab:workspace`），不進電路檔；瀏覽器不允許時就不記。

## 2. 平板兩指縮放

- 邏輯圖畫布上兩指縮放與平移，和麵包板一樣（`pinchViewport`）。一指拖曳空白處仍是平移。

## 3. 框選

- 在空白處按住 Shift 拖曳：畫出框，放開時選取框內（元件方框和框有重疊就算）的所有元件。選取改成可以是多個元件（`{ kind: 'nodes', ids }`）。
- 拖曳選取中的任一個元件：整組一起移動；有任何一個會和其他元件重疊時整組不動（`moveNodes`）。
- Del：刪除整組（連同它們的線）。Esc：取消選取。

## 4. 複製貼上

- Ctrl+C：複製選取的元件（一個或多個）與兩端都在選取範圍內的線。
- Ctrl+V：貼上，往右下偏移 2 格；放不下就繼續往右下找（每次再偏移 2 格，最多 20 次）。
  - 新的元件拿到新的 ID；輸入端、輸出端的名稱和現有的重複時，換成還沒用過的名稱（輸入端從 A 開始、輸出端從 X 開始找）。
  - 貼上後選取新貼上的那一組。
- 複製的內容只放在這個分頁的記憶體裡，不用系統剪貼簿。

## 5. 復原

- 移動一組、刪除一組、貼上：各是一個 Undo 步驟。

## 6. 測試

- 單元：`moveNodes`（整組移動、重疊就不動）、`copyNodes` / `pasteNodes`（ID、名稱、只帶內部的線、偏移與找空位）、框選的範圍判斷、記住畫面。
- 端對端：Shift 拉框選 3 個元件 → 拖曳整組 → Ctrl+C / Ctrl+V 後元件與線變多 → 重新整理後仍在邏輯圖。
